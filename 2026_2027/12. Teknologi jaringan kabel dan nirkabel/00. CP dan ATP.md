## ALUR TUJUAN PEMBELAJARAN (ATP) KELAS XII TKJ

### TP 1 — Konsep Jaringan Berbasis Server

Peserta didik mempelajari konsep jaringan client-server dan peer-to-peer serta memahami fungsi server sebagai penyedia layanan bagi client.

Materi meliputi:

* Konsep client-server
* Konsep peer-to-peer
* Fungsi server
* Fungsi client
* Sistem operasi server
* Layanan jaringan
* DHCP Server
* DNS Server
* Web Server
* File Server
* Proxy Server

Peserta didik mampu menjelaskan hubungan antara server, client, perangkat jaringan, dan layanan jaringan.

---

### TP 2 — Instalasi dan Administrasi Sistem Operasi Server

Peserta didik melakukan instalasi sistem operasi server dan melakukan konfigurasi dasar untuk mempersiapkan server sebagai penyedia layanan jaringan.

Materi meliputi:

* Pengenalan Linux Server
* Instalasi sistem operasi server
* Konfigurasi hostname
* Konfigurasi IP address
* Konfigurasi gateway
* Konfigurasi DNS
* Manajemen user
* Manajemen group
* Hak akses file dan folder
* Permission
* Perintah dasar Linux
* Remote server
* SSH

Peserta didik mampu menginstal dan mengelola sistem operasi server menggunakan prosedur yang benar.

---

### TP 3 — DHCP dan DNS Server

Peserta didik melakukan konfigurasi DHCP Server untuk memberikan alamat IP secara otomatis kepada client dan DNS Server untuk menyediakan layanan penerjemahan nama domain.

Materi meliputi:

* Konsep DHCP
* DHCP Server
* DHCP Client
* IP address otomatis
* IP address statis
* DHCP range
* Gateway dan DNS
* Konsep DNS
* Domain
* DNS Server
* Forward lookup
* Konfigurasi domain lokal
* Pengujian DHCP dan DNS

Peserta didik mampu membuat layanan DHCP dan DNS serta melakukan pengujian dari komputer client.

---

### TP 4 — Web Server dan File Server

Peserta didik melakukan instalasi dan konfigurasi Web Server dan File Server pada jaringan lokal.

Materi meliputi:

* Konsep Web Server
* Fungsi Web Server
* Apache atau Nginx
* Struktur direktori web
* Virtual Host
* Konfigurasi website lokal
* Konsep File Server
* Sharing file
* User dan permission
* Pengaturan hak akses
* Pengujian Web Server
* Pengujian File Server

Peserta didik mampu menyediakan layanan website dan berbagi file melalui jaringan lokal.

---

### TP 5 — Routing dan NAT

Peserta didik memahami proses komunikasi antarjaringan dan melakukan konfigurasi routing untuk menghubungkan beberapa jaringan.

Materi meliputi:

* Konsep routing
* Router
* Gateway
* Routing table
* Static routing
* Dynamic routing sebagai pengenalan
* Inter-network communication
* NAT
* Masquerade
* Port forwarding sebagai pengenalan
* Pengujian routing
* Troubleshooting routing

Peserta didik mampu menghubungkan beberapa jaringan menggunakan konfigurasi routing dan NAT.

---

Peserta didik menerapkan keamanan pada jaringan dan server untuk mengontrol akses terhadap sumber daya jaringan.

Peserta didik melakukan monitoring jaringan dan menganalisis permasalahan berdasarkan data yang diperoleh dari perangkat maupun aplikasi monitoring.

### Urutan kompetensi kelas XII

**Konsep Server → Sistem Operasi Server → DHCP & DNS → Web/File Server → Routing & NAT → Keamanan Jaringan → Monitoring & Troubleshooting → Proyek Jaringan Terintegrasi**

Dengan susunan ini, kelas XII tidak mengulang materi kelas XI, tetapi lebih diarahkan pada **administrasi jaringan dan implementasi jaringan secara menyeluruh**, sehingga cocok sebagai tahap lanjutan sebelum peserta didik masuk ke dunia kerja atau PKL/sertifikasi.
