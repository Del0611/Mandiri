# UNIT 1: PROSES BISNIS DI BIDANG TJKT

## BAB 1: PENDAHULUAN PROSES BISNIS TJKT

### 1.1 Pengertian Proses Bisnis di TJKT

> **Proses bisnis** adalah serangkaian aktivitas terstruktur dan saling terkait yang mengubah input menjadi output bernilai bagi pelanggan.

Di bidang TJKT, proses bisnis mencakup seluruh alur kegiatan mulai dari:
- **Perencanaan** infrastruktur jaringan
- **Implementasi** (instalasi, konfigurasi)
- **Pelayanan** kepada pelanggan
- **Pemeliharaan** dan peningkatan mutu

### 1.2 Mengapa Proses Bisnis Penting di TJKT?

| Alasan | Penjelasan |
|--------|------------|
| **Efisiensi Operasional** | Proses yang baik menghemat waktu dan biaya |
| **Konsistensi Layanan** | Setiap pelanggan mendapat layanan yang sama |
| **Kepuasan Pelanggan** | Proses yang cepat dan tepat meningkatkan kepuasan |
| **Keunggulan Kompetitif** | Perusahaan dengan proses baik lebih unggul |
| **Keberlanjutan Bisnis** | Proses yang terdokumentasi memudahkan regenerasi |

## BAB 2: PERENCANAAN (PLANNING) DALAM BISNIS TJKT

### 2.1 Pengertian Perencanaan

> **Perencanaan** adalah proses menentukan tujuan dan langkah-langkah yang diperlukan untuk mencapainya.

Dalam bisnis TJKT, perencanaan mencakup:
- Perencanaan strategis (jangka panjang)
- Perencanaan taktis (menengah)
- Perencanaan operasional (harian/mingguan)

### 2.2 Tahapan Perencanaan Proyek Jaringan

```

│     ├── Analisis kebutuhan pelanggan                               │

│                                                                     │
│  2. STUDI KELAYAKAN                                                │
│     ├── Kelayakan teknis (apakah teknologi tersedia?)              │

### 2.3 Contoh Perencanaan: ISP Baru di Kecamatan X

**Kasus:** PT. Jaringan Cepat ingin membuka layanan internet di Kecamatan X dengan 5 desa.

**Rencana yang disusun:**

| Aspek | Perencanaan |
|-------|-------------|
| **Kebutuhan** | Survei menunjukkan 1.200 rumah potensial, kebutuhan bandwidth rata-rata 20 Mbps |
| **Teknologi** | Menggunakan FTTH (Fiber to the Home) dengan GPON |
| **Perangkat** | 1 OLT, 40 ODP, 1.200 ONT, kabel fiber 50 km |
| **Anggaran** | Rp 1,5 Miliar (perangkat + instalasi) |
| **Tim** | 1 Project Manager, 5 teknisi, 2 marketing, 1 admin |
| **Jadwal** | 3 bulan (bulan 1: pengadaan, bulan 2: instalasi, bulan 3: testing & go-live) |
| **Target** | 500 pelanggan dalam 6 bulan pertama |

### 2.4 Dokumen Perencanaan yang Harus Ada

| Dokumen | Fungsi |
|---------|--------|
| **Project Charter** | Dokumen otorisasi proyek |
| **SOW (Statement of Work)** | Ruang lingkup pekerjaan |
| **Bill of Materials (BOM)** | Daftar perangkat yang dibutuhkan |
| **Network Design Document** | Desain jaringan |
| **RAB (Rencana Anggaran Biaya)** | Perhitungan biaya |
| **Schedule/Timeline** | Jadwal pelaksanaan |

### 2.5 Perencanaan Sumber Daya Manusia (SDM)

| Kebutuhan SDM | Jumlah | Kualifikasi |
|---------------|--------|-------------|
| Project Manager | 1 | Sertifikasi PMP/PRINCE2, pengalaman 5+ tahun |
| Network Engineer | 2 | Sertifikasi CCNA/CCNP |
| Field Teknisi | 5 | Pengalaman instalasi fiber & konfigurasi |
| Marketing | 2 | Pengalaman di bidang telekomunikasi |
| Admin/CS | 1 | Kemampuan administrasi dan komunikasi |

## BAB 3: IMPLEMENTASI (EXECUTION) DALAM BISNIS TJKT

### 3.1 Pengertian Implementasi

> **Implementasi** adalah tahap pelaksanaan dari rencana yang telah dibuat, mengubah desain menjadi realitas operasional.

Dalam TJKT, implementasi mencakup:
- Instalasi fisik jaringan
- Konfigurasi perangkat
- Pengujian dan validasi
- Serah terima (handover)

### 3.2 Tahapan Implementasi Proyek Jaringan

```
┌─────────────────────────────────────────────────────────────────────┐
│                TAHAPAN IMPLEMENTASI PROYEK JARINGAN                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  TAHAP 1: PERSIAPAN                                               │
│  ├── Pengecekan perangkat (quality control)                        │
│  ├── Persiapan alat dan bahan                                     │
│  ├── Briefing tim                                                 │
│  └── Koordinasi dengan pelanggan (izin lokasi, jadwal)           │
│                                                                     │
│  TAHAP 2: INSTALASI FISIK                                         │
│  ├── Pemasangan kabel (trenching, ducting, aerial)               │

│  └── Grounding dan proteksi                                      │
│                                                                     │
│  TAHAP 3: KONFIGURASI                                             │

### 3.5 Contoh Kasus: Implementasi Jaringan di Sekolah

**Proyek:** Instalasi jaringan Wi-Fi di SMK Negeri 1 Kota Y (30 ruang kelas + 5 laboratorium)

**Implementasi:**

| Tahap | Aktivitas | Waktu |
|-------|-----------|-------|
| Survey | Mengukur luas area, menentukan titik AP | 1 hari |
| Pengadaan | Membeli 35 Access Point, switch POE, kabel | 2 minggu |
| Instalasi | Pemasangan AP di setiap ruang, pengkabelan | 5 hari |
| Konfigurasi | Setup SSID, VLAN untuk guru & siswa, captive portal | 2 hari |
| Testing | Uji coba di setiap ruang, perbaikan titik lemah | 2 hari |
| Handover | Pelatihan IT sekolah, serah terima dokumen | 1 hari |

**Hasil:** Jaringan berhasil dengan coverage 100% area, kecepatan rata-rata 100 Mbps.

## BAB 4: PELAYANAN PELANGGAN (CUSTOMER SERVICE)

### 4.1 Pengertian Pelayanan Pelanggan

> **Pelayanan pelanggan** adalah totalitas aktivitas yang dilakukan perusahaan untuk memenuhi kebutuhan dan harapan pelanggan, baik sebelum, selama, maupun setelah transaksi.

Dalam bisnis TJKT, pelayanan pelanggan mencakup:
- Layanan pra-penjualan (informasi, konsultasi)
- Layanan saat penjualan (instalasi, aktivasi)
- Layanan pasca-penjualan (dukungan, maintenance)

### 4.3 Channel Pelayanan Pelanggan

| Channel | Keunggulan | Contoh |
|---------|------------|--------|
| **Telepon** | Langsung, personal | Call center ISP |
| **WhatsApp/Email** | Terdokumentasi, fleksibel | CS via WA |
| **Aplikasi/Website** | Self-service, 24/7 | Portal pelanggan |
| **Datang Langsung** | Solusi cepat | Gerai/plaza |
| **Media Sosial** | Publik, cepat viral | Twitter, Instagram |

### 4.4 Standar Layanan (SLA - Service Level Agreement)

**SLA** adalah perjanjian tingkat layanan antara penyedia dan pelanggan.

| Parameter SLA | Target Contoh | Penjelasan |
|---------------|---------------|------------|
| **Uptime** | 99,9% | Jaringan tersedia 99,9% dalam sebulan |
| **Response Time** | < 30 menit | Waktu respon awal untuk keluhan |
| **Resolution Time** | < 4 jam | Waktu penyelesaian gangguan |
| **Installation Time** | 3 hari | Waktu instalasi baru |
| **Speed** | Minimal 80% | Kecepatan internet sesuai paket |

### 4.6 Contoh Skenario: Menangani Keluhan

**Kasus:** Pelanggan bernama Pak Ahmad menelepon CS karena internetnya mati sejak pagi.

**Implementasi pelayanan:**

```
📞 PELANGGAN: "Selamat pagi, internet saya mati sejak jam 8 pagi. Saya sudah coba restart modem tapi tidak bisa."

👩‍💼 CS: "Baik Pak, mohon maaf atas ketidaknyamanannya. Saya catat dulu ya..."
   → Mencatat ID pelanggan, alamat, dan keluhan
   → Membuat tiket #TKT-2026-001

👩‍💼 CS: "Pak, saya cek dari sistem... ternyata di area Bapak ada pemadaman listrik yang mempengaruhi node kami. Tim sedang perbaiki dan target selesai jam 2 siang."

👩‍💼 CS: "Saya akan SMS/WA update ke Bapak ya. Mohon maaf atas gangguannya."

📝 CS mencatat di sistem: "Gangguan karena pemadaman listrik, progress perbaikan."
⏰ CS melakukan follow-up setelah jam 2 siang untuk memastikan internet kembali normal.
   → Setelah normal, CS mengonfirmasi ke pelanggan.
   → Tiket ditutup (closed).

⭐ Hasil: Pelanggan puas karena mendapat informasi yang jelas dan update.
```

### 4.7 Etika Pelayanan Pelanggan

| Prinsip | Contoh |
|---------|--------|

### 5.6 Penerapan Budaya Mutu di Perusahaan TJKT

| Aktivitas | Tujuan | Frekuensi |
|-----------|--------|-----------|
| **Standar Operasi Prosedur (SOP)** | Panduan kerja yang jelas | Dibuat sekali, direvisi berkala |
| **Quality Control (QC)** | Pengecekan kualitas instalasi | Setiap proyek |
| **Quality Assurance (QA)** | Memastikan proses sesuai standar | Setiap bulan |
| **Audit Internal** | Evaluasi sistem mutu | 6 bulan sekali |
| **Pelatihan Karyawan** | Meningkatkan kompetensi | 1 tahun sekali |
| **Survei Pelanggan** | Mendapatkan feedback | 3 bulan sekali |

### 5.7 Contoh Budaya Mutu dalam Tindakan

**Kasus:** Sebuah ISP menemukan bahwa 15% pelanggan mengeluhkan internet lambat di malam hari.

**Penerapan budaya mutu:**

```
1. Tim menganalisis root cause (penyebab):
   → Bandwidth jam sibuk melebihi kapasitas

2. Tim merencanakan perbaikan (Plan):
   → Upgrade kapasitas backbone dari 10 Gbps ke 20 Gbps

3. Implementasi (Do):
   → Melakukan upgrade selama 2 minggu

4. Monitoring (Check):
   → Memonitor performa setelah upgrade

5. Perbaikan berkelanjutan (Act):
   → Jika masih ada keluhan, tambah optimasi QoS
   → Dokumentasikan pembelajaran untuk proyek selanjutnya

Hasil: Keluhan turun dari 15% menjadi 3%.
```

### 5.8 Prinsip Mutu untuk Teknisi TJKT

| Prinsip | Penerapan |
|---------|-----------|
| **Kerjakan dengan benar sejak awal** | Instalasi rapi, tidak asal-asalan |
| **Berkomunikasi dengan baik** | Informasi yang jelas ke pelanggan |
| **Tanggung jawab pribadi** | Bertanggung jawab atas pekerjaan sendiri |
| **Belajar dari kesalahan** | Evaluasi setiap gangguan |
| **Terus belajar** | Ikuti perkembangan teknologi |
| **Keselamatan kerja** | Patuhi protokol keamanan |

### 7.2 Software Defined Networking (SDN)

**SDN** adalah pendekatan arsitektur jaringan di mana kontrol jaringan (control plane) dipisahkan dari perangkat keras (data plane).

```
┌─────────────────────────────────────────────────────────────────────┐
│                ARSITEKTUR SDN                                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   ┌─────────────────────────────────────────────────────────┐      │
│   │              APPLICATION LAYER                           │      │
│   │   (Firewall, Load Balancer, Monitoring, dll.)           │      │
│   └──────────────────────┬──────────────────────────────────┘      │
│                          │ API (Northbound)                         │
│   ┌──────────────────────┴──────────────────────────────────┐      │
│   │              CONTROL LAYER                              │      │
│   │         (SDN Controller - ONOS, OpenDaylight)          │      │
│   └──────────────────────┬──────────────────────────────────┘      │
│                          │ API (Southbound - OpenFlow)            │
│   ┌──────────────────────┴──────────────────────────────────┐      │
│   │              INFRASTRUCTURE LAYER                        │      │
│   │    (Switch, Router, Access Point - Hardware)            │      │
│   └──────────────────────────────────────────────────────────┘      │
│                                                                     │
│  KEUNTUNGAN SDN:                                                   │
│  1. Fleksibel - konfigurasi dari pusat                            │
│  2. Efisien - otomatisasi                                         │
│  3. Hemat biaya - hardware generik                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 7.3 Network Automation

**Network Automation** adalah penggunaan software untuk mengelola dan mengkonfigurasi perangkat jaringan secara otomatis.

**Tools yang umum digunakan:**
- **Ansible** - Otomatisasi konfigurasi
- **Python + Netmiko** - Scripting untuk perangkat network
- **NAPALM** - Library untuk multi-vendor
- **Terraform** - Infrastructure as Code

**Contoh Skenario:**
```
Misal: Perusahaan ingin mengubah VLAN di 100 switch.
● Manual: 100 x 5 menit = 500 menit (8 jam)
● Automation: 1 script = 5 menit
```
