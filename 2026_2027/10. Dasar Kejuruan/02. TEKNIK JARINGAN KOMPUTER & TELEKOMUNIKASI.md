# UNIT 1: K3LH DAN BUDAYA KERJA INDUSTRI

## BAB 1: PENGERTIAN K3LH DI BIDANG TJKT

### 1.1 Pengertian K3LH

**K3LH** adalah singkatan dari **Keselamatan, Kesehatan Kerja, dan Lingkungan Hidup**.

**Definisi menurut para ahli:**

> **K3LH** adalah upaya untuk melindungi tenaga kerja dari risiko kecelakaan dan penyakit akibat kerja, serta menjaga kelestarian lingkungan hidup di sekitar tempat kerja.

### 1.2 Tujuan K3LH

```
┌─────────────────────────────────────────────────────────────────────┐
│                     TUJUAN K3LH                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. MELINDUNGI PEKERJA                                            │
│     └── Menjamin keselamatan dan kesehatan pekerja               │
│                                                                     │
│  2. MENCEGAH KECELAKAAN KERJA                                     │
│     └── Mengurangi risiko kecelakaan di tempat kerja              │
│                                                                     │
│  3. MENCEGAH PENYAKIT AKIBAT KERJA                                │
│     └── Menghindari penyakit yang timbul dari pekerjaan           │
│                                                                     │
│  4. MENJAGA LINGKUNGAN                                            │
│     └── Melindungi lingkungan dari dampak negatif kegiatan        │
│                                                                     │
│  5. MENINGKATKAN PRODUKTIVITAS                                    │
│     └── Pekerja yang sehat dan aman lebih produktif              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.3 Dasar Hukum K3 di Indonesia

| Undang-Undang | Isi Pokok |
|---------------|-----------|
| **UU No. 1 Tahun 1970** | Keselamatan Kerja |
| **UU No. 23 Tahun 1992** | Kesehatan |
| **UU No. 32 Tahun 2009** | Perlindungan dan Pengelolaan Lingkungan Hidup |
| **PP No. 50 Tahun 2012** | Penerapan SMK3 (Sistem Manajemen K3) |

### 1.4 Ruang Lingkup K3LH di Bidang TJKT

Di bidang Teknik Jaringan Komputer dan Telekomunikasi, K3LH mencakup:

| Aspek | Penerapan |
|-------|-----------|
| **Keselamatan Kerja** | Bekerja di ketinggian (tower, tiang), kelistrikan, penggunaan alat berat |
| **Kesehatan Kerja** | Ergonomi komputer, paparan radiasi, kebisingan |
| **Lingkungan Hidup** | Pembuangan limbah elektronik (e-waste), penggunaan energi hemat |

### 1.5 Mengapa K3LH Penting di Bidang TJKT?

```
┌─────────────────────────────────────────────────────────────────────┐
│           ALASAN K3LH PENTING DI BIDANG TJKT                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ☐  Pekerjaan sering dilakukan di ketinggian (tower, tiang)       │
│  ☐  Berhubungan dengan listrik dan perangkat elektronik           │

│  ☐  Paparan debu dan bahan kimia (pembersih, solder)             │
│  ☐  Risiko kecelakaan lalu lintas saat bekerja di lapangan        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## BAB 3: ALAT PELINDUNG DIRI (APD) DI BIDANG TJKT

### 3.1 Pengertian Alat Pelindung Diri (APD)

> **Alat Pelindung Diri (APD)** adalah peralatan yang digunakan oleh pekerja untuk melindungi diri dari bahaya di tempat kerja.

### 3.2 Jenis-Jenis APD di Bidang TJKT

```
┌─────────────────────────────────────────────────────────────────────┐
│              JENIS-JENIS APD DI BIDANG TJKT                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. PELINDUNG KEPALA                                               │
│     ├── Helm proyek (hard hat)                                    │
│     └── Penutup rambut (untuk area bersih)                        │
│                                                                     │
│  2. PELINDUNG MATA DAN WAJAH                                      │
│     ├── Kacamata pengaman                                         │
│     ├── Goggle (kacamata pelindung)                              │
│     └── Pelindung wajah (face shield)                            │
│                                                                     │
│  3. PELINDUNG TELINGA                                             │
│     ├── Ear plug (penyumbat telinga)                             │
│     └── Ear muff (penutup telinga)                               │
│                                                                     │
│  4. PELINDUNG TANGAN                                              │
│     ├── Sarung tangan (berbagai jenis)                            │
│     ├── Sarung tangan anti listrik                                │
│     └── Sarung tangan anti potong                                 │
│                                                                     │
│  5. PELINDUNG KAKI                                                │
│     ├── Sepatu safety (bersol baja)                              │
│     └── Sepatu anti slip                                         │
│                                                                     │
│  6. PELINDUNG TUBUH                                               │
│     ├── Rompi safety (vest)                                      │
│     ├── Sabuk pengaman (safety belt)                             │
│     └── Baju kerja (coverall)                                    │
│                                                                     │
│  7. PELINDUNG PERNAPASAN                                          │
│     ├── Masker debu                                               │
│     └── Respirator                                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.3 Penggunaan APD Berdasarkan Pekerjaan

| Pekerjaan | APD yang Dibutuhkan |
|-----------|---------------------|
| **Instalasi tower/tiang** | Helm, sabuk pengaman, sepatu safety, sarung tangan |
| **Instalasi kabel** | Helm, sepatu safety, sarung tangan, kacamata |
| **Splicing fiber** | Kacamata, masker, sarung tangan, baju kerja |
| **Pekerjaan listrik** | Sarung tangan anti listrik, sepatu isolasi |
| **Pekerjaan di ruang sempit** | Helm, masker, senter, rompi safety |

### 3.4 Cara Perawatan APD

```
┌─────────────────────────────────────────────────────────────────────┐
│                    CARA PERAWATAN APD                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ☐  Helm                                                    │
│     └── Bersihkan dengan kain lembab, periksa retakan              │
│                                                                     │
│  ☐  Kacamata/Goggle                                           │
│     └── Bersihkan dengan kain microfiber, simpan di tempat aman    │
│                                                                     │
│  ☐  Sarung tangan                                           │
│     └── Cuci sesuai petunjuk, periksa kerusakan                    │
│                                                                     │
│  ☐  Sepatu safety                                            │
│     └── Bersihkan dan poles secara rutin                           │
│                                                                     │
│  ☐  Sabuk pengaman                                          │
│     └── Periksa tali dan pengait sebelum digunakan                 │
│                                                                     │
│  ☐  Masker/Respirator                                        │
│     └── Ganti secara berkala, simpan di tempat kering             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.5 Prosedur Penggunaan APD

1. **Periksa APD** sebelum digunakan (pastikan tidak rusak)
2. **Pakai APD** dengan benar sesuai fungsinya
3. **Gunakan APD** selama berada di area kerja
4. **Simpan APD** di tempat yang telah ditentukan
5. **Laporkan** jika APD rusak atau hilang

## BAB 7: MODEL REFERENSI OSI DAN TCP/IP

### 7.1 Model OSI (Open Systems Interconnection)

**Model OSI** adalah standar internasional yang menggambarkan bagaimana data dikirimkan melalui jaringan. Model ini terdiri dari 7 lapisan (layer).

```
┌─────────────────────────────────────────────────────────────────────┐
│               MODEL OSI (7 LAPISAN)                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────────┐│
│  │  7. APPLICATION  (Aplikasi)   →  User interface               ││
│  │     Contoh: HTTP, FTP, SMTP                                   ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  6. PRESENTATION (Presentasi) →  Format data, enkripsi        ││
│  │     Contoh: JPEG, MPEG, SSL                                   ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  5. SESSION     (Sesi)        →  Manajemen sesi komunikasi    ││
│  │     Contoh: NetBIOS, RPC                                      ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  4. TRANSPORT   (Transport)   →  Pengiriman data end-to-end   ││
│  │     Contoh: TCP, UDP                                          ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  3. NETWORK    (Jaringan)     →  Pengalamatan dan routing     ││
│  │     Contoh: IP, ICMP, ARP                                     ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  2. DATA LINK  (Data Link)    →  Pengiriman frame antar node  ││
│  │     Contoh: Ethernet, PPP                                     ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  1. PHYSICAL   (Fisik)        →  Media transmisi fisik        ││
│  │     Contoh: Kabel, fiber, sinyal radio                        ││
│  └─────────────────────────────────────────────────────────────────┘│
│                                                                     │
│  🔑  TIPS MENGHAPAL:                                               │
│      "Please Do Not Throw Sausage Pizza Away"                     │
│      (Physical, Data-link, Network, Transport, Session,            │
│       Presentation, Application)                                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 7.2 Model TCP/IP

**TCP/IP** adalah protokol utama yang digunakan di internet. Model ini terdiri dari 4 lapisan.

```
┌─────────────────────────────────────────────────────────────────────┐
│              MODEL TCP/IP (4 LAPISAN)                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────────┐│
│  │  4. APPLICATION    →  HTTP, FTP, SMTP, DNS                    ││
│  │     (Aplikasi)                                                 ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  3. TRANSPORT     →  TCP, UDP                                 ││
│  │     (Transport)                                               ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  2. INTERNET      →  IP, ICMP, ARP                           ││
│  │     (Internet)                                                ││
│  ├─────────────────────────────────────────────────────────────────┤│
│  │  1. NETWORK ACCESS →  Ethernet, Wi-Fi, PPP                   ││
│  │     (Akses Jaringan)                                          ││
│  └─────────────────────────────────────────────────────────────────┘│
│                                                                     │

```

## BAB 8: PENGALAMATAN IP DAN SUBNETTING

### 8.1 Pengertian IP Address

> **IP Address (Internet Protocol Address)** adalah alamat unik yang digunakan untuk mengidentifikasi setiap perangkat di jaringan.

### 8.2 Format IP Address

```
Contoh: 192.168.1.100
         │   │   │   │
         │   │   │   └── Oktet ke-4
         │   │   └────── Oktet ke-3
         │   └────────── Oktet ke-2
         └────────────── Oktet ke-1
```

### 8.3 Kelas IP Address

```
┌─────────────────────────────────────────────────────────────────────┐
│                   KELAS IP ADDRESS                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌────────────┬──────────────┬─────────────────────────────────┐  │
│  │  Kelas     │  Range IP    │  Penggunaan                     │  │
│  ├────────────┼──────────────┼─────────────────────────────────┤  │
│  │  A         │ 1.0.0.0 -    │ Jaringan besar (negara)         │  │
│  │            │ 126.255.255.255│                               │  │
│  ├────────────┼──────────────┼─────────────────────────────────┤  │
│  │  B         │ 128.0.0.0 -  │ Jaringan menengah (kota)       │  │
│  │            │ 191.255.255.255│                               │  │
│  ├────────────┼──────────────┼─────────────────────────────────┤  │
│  │  C         │ 192.0.0.0 -  │ Jaringan kecil (kantor)        │  │

│  │  D         │ 224.0.0.0 -  │ Multicast                      │  │
│  │            │ 239.255.255.255│                               │  │
│  ├────────────┼──────────────┼─────────────────────────────────┤  │
│  │  E         │ 240.0.0.0 -  │ Eksperimental                  │  │

│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 8.4 IP Private vs Public

| Jenis | Range IP | Penggunaan |
|-------|----------|------------|
| **Private** | 10.0.0.0 - 10.255.255.255 | Jaringan internal (tidak terhubung langsung ke internet) |
| | 172.16.0.0 - 172.31.255.255 | |
| | 192.168.0.0 - 192.168.255.255 | |
| **Public** | Semua lainnya | Terhubung ke internet |

### 8.5 Subnet Mask

> **Subnet Mask** digunakan untuk membagi jaringan menjadi beberapa subnet.

**Contoh Subnet Mask:**

| CIDR | Subnet Mask | Jumlah Host |
|------|-------------|-------------|
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /27 | 255.255.255.224 | 30 |
| /28 | 255.255.255.240 | 14 |
| /29 | 255.255.255.248 | 6 |
| /30 | 255.255.255.252 | 2 |

### 8.6 Subnetting

**Contoh Subnetting Sederhana:**

```
Diberikan: 192.168.1.0 /24 (255.255.255.0)
Dibutuhkan: 4 subnet

Langkah:
1. 2^n ≥ 4 (n = 2 bit untuk subnet)
2. Subnet mask baru: /26 (255.255.255.192)
3. Subnet yang dihasilkan:
   - 192.168.1.0/26   (1 - 62)
   - 192.168.1.64/26  (65 - 126)
   - 192.168.1.128/26 (129 - 190)
   - 192.168.1.192/26 (193 - 254)
```

### 8.7 IPv6

> **IPv6** adalah versi terbaru IP Address dengan 128 bit untuk mengatasi keterbatasan IPv4.

**Format IPv6:** 8 kelompok 16-bit dipisahkan titik dua

```
Contoh: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

```

├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. ROUTER                                                        │

│     └── Contoh: Router MikroTik, Cisco                           │

│     └── Contoh: TP-Link, Ubiquiti                                │
│                                                                     │
│  5. MODEM                                                         │

```

### 9.2 Perbandingan Perangkat Jaringan

| Perangkat | Layer OSI | Fungsi Utama |
|-----------|-----------|--------------|
| Hub | Layer 1 (Physical) | Menghubungkan perangkat |
| Switch | Layer 2 (Data Link) | Menghubungkan perangkat dalam LAN |
| Router | Layer 3 (Network) | Menghubungkan jaringan berbeda |
| Access Point | Layer 1-2 | Menyediakan koneksi nirkabel |

### 9.3 Konfigurasi Dasar Perangkat Jaringan

```
┌─────────────────────────────────────────────────────────────────────┐
│              KONFIGURASI DASAR PERANGKAT JARINGAN                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. SETTING IP ADDRESS                                             │
│     └── Memberi alamat IP pada perangkat                          │
│     └── Contoh: ip address 192.168.1.1/24                         │
│                                                                     │
│  2. SETTING GATEWAY                                                │
│     └── Menentukan jalur keluar ke jaringan lain                  │
│     └── Contoh: ip route 0.0.0.0/0 192.168.1.254                  │
│                                                                     │
│  3. SETTING DNS                                                    │
│     └── Menerjemahkan domain ke IP                               │
│     └── Contoh: 8.8.8.8 (Google DNS)                             │
│                                                                     │
│  4. SETTING DHCP                                                   │
│     └── Memberi IP secara otomatis ke perangkat client            │
│                                                                     │
│  5. SETTING FIREWALL                                               │
│     └── Melindungi jaringan dari akses tidak sah                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 9.4 Contoh Konfigurasi Dasar Router MikroTik

```
[CONTOH KONFIGURASI ROUTER MIKROTIK]

1. Setting IP Address
   /ip address add address=192.168.1.1/24 interface=ether1

2. Setting DHCP Server
   /ip pool add name=dhcp-pool ranges=192.168.1.10-192.168.1.254
   /ip dhcp-server add name=dhcp1 interface=ether1 address-pool=dhcp-pool

3. Setting NAT (Network Address Translation)
   /ip firewall nat add chain=srcnat out-interface=ether2 action=masquerade

4. Setting DNS
   /ip dns set servers=8.8.8.8 allow-remote-requests=yes
```

## BAB 12: TEKNOLOGI FIBER OPTIK

### 12.1 Pengertian Fiber Optik

> **Fiber optik** adalah media transmisi yang menggunakan cahaya sebagai pembawa data melalui serat kaca atau plastik.

### 12.2 Struktur Kabel Fiber Optik

```
┌─────────────────────────────────────────────────────────────────────┐
│                STRUKTUR KABEL FIBER OPTIK                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────────┐│
│  │  ┌──┐ ┌──┐ ┌──┐ ┌──┐                                         ││
│  │  │CL│ │CL│ │CL│ │CL│  → Coating/Lapisan Pelindung             ││
│  │  └──┘ └──┘ └──┘ └──┘                                         ││
│  │  ┌───────────────────────┐                                    ││
│  │  │    Cladding           │  → Pembungkus (memantulkan cahaya)││
│  │  ├───────────────────────┤                                    ││
│  │  │      Core             │  → Inti (tempat cahaya)            ││
│  │  └───────────────────────┘                                    ││
│  └─────────────────────────────────────────────────────────────────┘│
│                                                                     │
│  Komponen:                                                         │
│  1. Core (Inti) - tempat rambat cahaya (8-62.5 μm)               │
│  2. Cladding - membungkus core, memantulkan cahaya               │
│  3. Coating - lapisan pelindung                                   │
│  4. Buffer - pelindung tambahan                                  │
│  5. Strength Member - penguat serat                              │
│  6. Outer Jacket - pembungkus luar                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 12.3 Prinsip Kerja Fiber Optik

```
┌─────────────────────────────────────────────────────────────────────┐
│                 PRINSIP KERJA FIBER OPTIK                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. DATA (listrik) → Konversi ke cahaya (LED/Laser)              │
│                                                                     │
│  2. Cahaya merambat di dalam core dengan prinsip refleksi total  │
│                                                                     │
│  3. Cahaya diterima oleh photodetector                          │
│                                                                     │
│  4. Cahaya → Konversi kembali ke data (listrik)                  │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────────┐│
│  │  [Data] → [Pemancar] → [Sinyal Cahaya] → [Fiber] → [Penerima] ││
│  │                (LED/Laser)                   (Photodetector)  ││
│  └─────────────────────────────────────────────────────────────────┘│
│                                                                     │
│  Prinsip Refleksi Total:                                          │
│  Cahaya dipantulkan sempurna karena perbedaan indeks bias        │
│  antara core dan cladding.                                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

| **Stripper** | Mengupas coating fiber |
| **Cleaver** | Memotong fiber dengan presisi |
| **Konektor SC/LC** | Menghubungkan fiber ke perangkat |
| **Kabel pigtail** | Kabel fiber dengan konektor |

### 12.5 Proses Penyambungan Fiber (Splicing)

```
┌─────────────────────────────────────────────────────────────────────┐
```

1. **Bersihkan** alat setelah digunakan

4. **Hindari** benturan dan jatuh
5. **Gunakan** sesuai fungsi dan spesifikasi
6. **Kalibrasi** secara berkala
7. **Baca** buku petunjuk penggunaan
8. **Jangan** membongkar alat tanpa keahlian
