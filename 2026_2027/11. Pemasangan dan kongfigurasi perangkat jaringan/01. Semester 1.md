## KONSEP DASAR JARINGAN KOMPUTER

<span id="bab1-1"></span>

### 1.1 APA ITU JARINGAN KOMPUTER?

**Jaringan komputer** adalah sekumpulan perangkat komputer dan perangkat lainnya yang saling terhubung satu sama lain menggunakan media transmisi tertentu, sehingga dapat saling berbagi data, informasi, dan sumber daya. 

**Bayangkan seperti ini:**

Bayangkan sebuah kantor dengan banyak karyawan. Tanpa jaringan, setiap karyawan bekerja sendiri-sendiri dengan komputernya masing-masing. Jika ingin berbagi file, mereka harus menggunakan flash disk. Jika ingin mencetak dokumen, mereka harus membawa flash disk ke printer. Ini tidak efisien.

Dengan jaringan komputer, semua komputer terhubung. Karyawan bisa:
- Berbagi file dengan mudah
- Mencetak dokumen ke printer bersama
- Berkomunikasi melalui email atau chat
- Mengakses data dari server pusat

**Definisi Formal:**

Jaringan komputer adalah sistem yang terdiri dari dua atau lebih perangkat komputasi yang terhubung menggunakan media transmisi (kabel atau nirkabel) untuk tujuan berbagi data dan sumber daya.

**Fungsi Dasar Jaringan Komputer:**

1. **Berbagi Sumber Daya** - Printer, scanner, hard disk, koneksi internet
2. **Berbagi Data** - File, database, dokumen
3. **Komunikasi** - Email, chat, video conference
4. **Akses Informasi** - Internet, intranet
5. **Pengelolaan Terpusat** - Administrasi, keamanan, backup

---

<span id="bab1-2"></span>

### 1.2 TUJUAN DAN MANFAAT JARINGAN KOMPUTER

**Tujuan Membangun Jaringan Komputer:**

| No | Tujuan | Penjelasan |
|----|--------|------------|
| 1 | **Berbagi Sumber Daya** | Mengoptimalkan penggunaan perangkat seperti printer, scanner, dan penyimpanan |
| 2 | **Komunikasi** | Memungkinkan komunikasi antar pengguna melalui email, chat, atau video |
| 3 | **Akses Informasi** | Memberikan akses ke data dan informasi dari mana saja |
| 4 | **Pengelolaan Terpusat** | Memudahkan administrasi dan pengelolaan data |
| 5 | **Keamanan Data** | Memudahkan implementasi keamanan dan backup data |

---

**Manfaat Jaringan Komputer:**

**1. Efisiensi Biaya**
- Mengurangi biaya perangkat (satu printer untuk banyak komputer)
- Mengurangi biaya penyimpanan (server pusat)
- Mengurangi biaya komunikasi (email vs surat)

**2. Efisiensi Waktu**
- Transfer data lebih cepat (file sharing)
- Komunikasi instan
- Akses data real-time

**3. Kolaborasi**
- Tim dapat bekerja bersama
- Berbagi dokumen secara langsung
- Revisi dokumen secara kolaboratif

**4. Skalabilitas**
- Mudah menambah perangkat baru
- Mudah memperluas jaringan
- Dapat berkembang sesuai kebutuhan

**5. Keandalan**
- Data tersimpan di server pusat
- Backup terpusat
- Redundansi untuk keandalan

---

<span id="bab1-3"></span>

### 1.3 KOMPONEN DASAR JARINGAN KOMPUTER

Setiap jaringan komputer terdiri dari beberapa komponen dasar yang saling bekerja sama:

**A. Perangkat Pengirim dan Penerima (End Devices)**

Perangkat yang menjadi sumber atau tujuan data dalam jaringan.

**Contoh:**
- Komputer/PC
- Laptop
- Smartphone
- Printer
- Server

**B. Media Transmisi**

Jalur yang digunakan untuk mengirim data dari satu perangkat ke perangkat lain. 

**Media Kabel:**
- Kabel UTP (Unshielded Twisted Pair)
- Kabel STP (Shielded Twisted Pair)
- Kabel Coaxial
- Kabel Fiber Optik

**Media Nirkabel:**
- Gelombang Radio (Wi-Fi)
- Gelombang Mikro
- Infrared
- Bluetooth

**C. Perangkat Jaringan (Networking Devices)**

Perangkat yang digunakan untuk menghubungkan dan mengelola jaringan. 

| Perangkat | Fungsi |
|-----------|--------|
| **Switch** | Menghubungkan perangkat dalam satu jaringan lokal |
| **Router** | Menghubungkan jaringan yang berbeda |
| **Access Point** | Menyediakan akses nirkabel |
| **Modem** | Menghubungkan jaringan ke ISP |
| **Firewall** | Mengamankan jaringan dari ancaman |

**D. Protokol Jaringan**

Aturan dan standar yang mengatur komunikasi antar perangkat. 

**Contoh:**
- **TCP/IP** - Protokol dasar internet
- **HTTP/HTTPS** - Protokol web
- **FTP** - Protokol transfer file
- **DNS** - Protokol penerjemahan domain

**E. Perangkat Lunak Jaringan**

Software yang mengelola komunikasi jaringan:

- **Sistem Operasi Jaringan** - Windows Server, Linux
- **Aplikasi Jaringan** - Web browser, email client
- **Utility Jaringan** - Ping, traceroute, ipconfig

---

<span id="bab1-4"></span>

### 1.4 JENIS-JENIS JARINGAN BERDASARKAN SKALA

**A. PAN (Personal Area Network)**

**Karakteristik:**
- Jaringan untuk satu orang
- Jarak: beberapa meter (hingga 10 meter)
- Kecepatan: rendah sampai sedang

**Contoh:**
- Bluetooth antara HP dan headset
- Koneksi USB antara komputer dan printer

---

**B. LAN (Local Area Network)**

**Karakteristik:**
- Jaringan dalam satu lokasi (gedung, kampus)
- Jarak: hingga beberapa kilometer
- Kecepatan: tinggi (100 Mbps - 10 Gbps)
- Kepemilikan: pribadi

**Contoh:**
- Jaringan komputer di sekolah
- Jaringan di kantor
- Jaringan di rumah

---

**C. MAN (Metropolitan Area Network)**

**Karakteristik:**
- Jaringan dalam satu kota
- Jarak: 10-50 km
- Kecepatan: sedang-tinggi
- Kepemilikan: bisa publik atau pribadi

**Contoh:**
- Jaringan antar kampus dalam satu kota
- Jaringan pemerintah kota
- Jaringan ISP kota

---

**D. WAN (Wide Area Network)**

**Karakteristik:**
- Jaringan antar kota, negara, atau benua
- Jarak: tidak terbatas
- Kecepatan: bervariasi
- Kepemilikan: publik (kecuali private WAN)

**Contoh:**
- Internet
- Jaringan antar cabang perusahaan
- Jaringan bank nasional

---

**E. Internet**

**Karakteristik:**
- Jaringan global
- Menghubungkan semua jaringan di dunia
- Menggunakan protokol TCP/IP
- Kepemilikan: publik

**Fakta:**
Internet adalah kumpulan dari jutaan jaringan yang terhubung secara global.

---

**Perbandingan Jenis Jaringan:**

| Aspek | PAN | LAN | MAN | WAN | Internet |
|-------|-----|-----|-----|-----|----------|
| Jarak | < 10 m | < 1 km | 10-50 km | > 50 km | Global |
| Kecepatan | Rendah | Tinggi | Sedang | Bervariasi | Bervariasi |
| Contoh | Bluetooth | Kantor | Kota | Antar negara | Seluruh dunia |

### 1.6 MODEL JARINGAN CLIENT-SERVER DAN PEER-TO-PEER

**A. Model Client-Server**

**Karakteristik:**
- Ada server yang menyediakan layanan
- Ada klien yang menggunakan layanan
- Server memiliki kontrol penuh
- Keamanan lebih baik
- Manajemen terpusat

**Ilustrasi:**
```
[Klien 1] ───┐
[Klien 2] ───┼─── [Server] ─── [Database]
[Klien 3] ───┘
```

**Keunggulan:**
- Keamanan tinggi
- Manajemen terpusat
- Skalabilitas
- Backup terpusat

**Kekurangan:**
- Biaya lebih tinggi
- Single point of failure (jika server down)
- Membutuhkan administrator

---

**B. Model Peer-to-Peer (P2P)**

**Karakteristik:**
- Semua perangkat setara
- Tidak ada server pusat
- Setiap perangkat bisa menjadi server dan klien
- Biaya rendah
- Tidak ada manajemen terpusat

**Ilustrasi:**
```
[Perangkat 1] ─── [Perangkat 2]
    │                │
    └─── [Perangkat 3]
```

**Keunggulan:**
- Biaya rendah
- Mudah diimplementasikan
- Tidak perlu server khusus
- Tidak perlu administrator

**Kekurangan:**
- Keamanan rendah
- Sulit dikelola
- Tidak scalable
- Tidak ada backup terpusat

---

**Perbandingan:**

| Aspek | Client-Server | Peer-to-Peer |
|-------|---------------|--------------|
| Server | Ada server pusat | Tidak ada |
| Keamanan | Tinggi | Rendah |
| Manajemen | Terpusat | Terdesentralisasi |
| Biaya | Tinggi | Rendah |
| Skalabilitas | Sangat baik | Terbatas |
| Contoh | Perusahaan, sekolah | Jaringan rumah |

### 2.1 APA ITU TOPOLOGI JARINGAN?

**Topologi jaringan** adalah susunan fisik dan logis dari perangkat-perangkat dalam suatu jaringan. Topologi menggambarkan bagaimana perangkat terhubung satu sama lain dan bagaimana data mengalir di dalam jaringan. 

**Bayangkan seperti ini:**

Bayangkan denah rumah. Ada berbagai cara untuk menghubungkan ruangan-ruangan:
- Semua ruangan terhubung ke satu koridor (seperti topologi bus)
- Ruangan terhubung melingkar (seperti topologi ring)
- Semua ruangan terhubung ke ruang tengah (seperti topologi star)

Setiap cara memiliki kelebihan dan kekurangannya masing-masing.

**Definisi Formal:**

Topologi jaringan adalah pola hubungan antar perangkat dalam jaringan, baik secara fisik (bagaimana kabel terhubung) maupun logis (bagaimana data mengalir). 

**Fungsi Topologi:**

1. Menentukan struktur jaringan
2. Menentukan jalur komunikasi data
3. Memudahkan troubleshooting
4. Memengaruhi performa jaringan

---

<span id="bab2-2"></span>

### 2.2 TOPOLOGI BUS

**Topologi Bus** adalah topologi di mana semua perangkat terhubung ke satu kabel utama (bus). 

**Ilustrasi:**
```
[PC1] ───┐
[PC2] ───┼─── [Kabel Utama/Bus] ─── [Terminator]
[PC3] ───┘
```

**Karakteristik:**
- Semua perangkat terhubung ke satu kabel utama
- Ada terminator di ujung kabel
- Data dikirim ke semua perangkat

**Cara Kerja:**
1. Komputer mengirim data ke kabel bus
2. Data menyebar ke semua komputer
3. Hanya komputer tujuan yang menerima data
4. Terminator menyerap sinyal di ujung kabel 

**Keunggulan:**
- Menghemat kabel
- Mudah diimplementasikan
- Biaya rendah

**Kekurangan:**
- Jika kabel utama putus, seluruh jaringan down
- Kinerja menurun jika banyak perangkat
- Sulit troubleshooting

**Penggunaan:**
- Jaringan sederhana
- Jaringan dengan jumlah perangkat sedikit

---

<span id="bab2-3"></span>

### 2.3 TOPOLOGI RING (CINCIN)

**Topologi Ring** adalah topologi di mana setiap perangkat terhubung ke dua perangkat lainnya membentuk lingkaran. 

**Ilustrasi:**
```
[PC1] ─── [PC2]
  │         │
  └─── [PC4] ─── [PC3]
```

**Karakteristik:**
- Setiap perangkat terhubung ke dua perangkat
- Membentuk lingkaran
- Data mengalir satu arah

**Cara Kerja:**
1. Komputer mengirim data
2. Data bergerak dari satu perangkat ke perangkat berikutnya
3. Setiap perangkat meneruskan data
4. Data sampai ke tujuan 

**Keunggulan:**
- Kinerja stabil
- Tidak ada tabrakan data (collision)
- Mudah untuk menambah perangkat

**Kekurangan:**
- Jika satu perangkat rusak, seluruh jaringan down
- Sulit troubleshooting
- Kecepatan transfer lambat jika banyak perangkat

**Penggunaan:**
- Jaringan dengan lalu lintas tinggi
- Jaringan yang membutuhkan stabilitas

---

<span id="bab2-4"></span>

### 2.4 TOPOLOGI STAR (BINTANG)

**Topologi Star** adalah topologi di mana semua perangkat terhubung ke satu perangkat pusat (switch/hub). 

**Ilustrasi:**
```
        [PC1]
         │
[PC2] ─── [Switch/Hub] ─── [PC3]
         │
        [PC4]
```

**Karakteristik:**
- Ada perangkat pusat (central device)
- Semua perangkat terhubung ke perangkat pusat
- Jika satu kabel putus, hanya perangkat itu yang terputus

**Cara Kerja:**
1. Komputer mengirim data ke perangkat pusat
2. Perangkat pusat meneruskan ke tujuan
3. Komunikasi melalui perangkat pusat 

**Keunggulan:**
- Sangat handal (satu kabel putus tidak mempengaruhi yang lain)
- Mudah troubleshooting
- Performa baik
- Mudah menambah perangkat
- Paling umum digunakan

**Kekurangan:**
- Biaya lebih tinggi (butuh switch/hub)
- Jika perangkat pusat rusak, seluruh jaringan down
- Butuh lebih banyak kabel

**Penggunaan:**
- Jaringan kantor
- Jaringan sekolah
- Jaringan rumah
- Paling umum digunakan

---

<span id="bab2-5"></span>

### 2.5 TOPOLOGI MESH (JALA)

**Topologi Mesh** adalah topologi di mana setiap perangkat terhubung ke semua perangkat lainnya.

**Ilustrasi:**
```
[PC1] ─── [PC2]
  │  \   /  │
  │   \ /   │
  │   / \   │
  │  /   \  │
[PC4] ─── [PC3]
```

**Karakteristik:**
- Setiap perangkat terhubung ke semua perangkat
- Ada banyak jalur alternatif
- Sangat handal

**Keunggulan:**
- Sangat handal (ada jalur alternatif)
- Tidak ada single point of failure
- Keamanan tinggi

**Kekurangan:**
- Biaya sangat tinggi
- Membutuhkan banyak kabel
- Sulit diimplementasikan

**Penggunaan:**
- Jaringan militer
- Jaringan bank
- Jaringan dengan keandalan tinggi

---

<span id="bab2-6"></span>

### 2.6 TOPOLOGI TREE (POHON)

**Topologi Tree** adalah kombinasi dari topologi bus dan star. Topologi ini memiliki struktur hirarkis seperti pohon. 

**Ilustrasi:**
```
           [Root/Induk]
           /    |    \
        [Switch] [Switch] [Switch]
         /   \     /   \    /   \
      [PC] [PC] [PC] [PC] [PC] [PC]
```

**Karakteristik:**
- Struktur hirarkis
- Kombinasi bus dan star
- Dapat diperluas dengan mudah

**Keunggulan:**
- Skalabilitas baik
- Manajemen terpusat
- Dapat diperluas

**Kekurangan:**
- Kompleks
- Jika root rusak, seluruh jaringan down
- Biaya lebih tinggi

**Penggunaan:**
- Jaringan kampus
- Jaringan perusahaan besar
- Jaringan multi-gudang

---

<span id="bab2-7"></span>

### 2.7 PERBANDINGAN TOPOLOGI JARINGAN

| Aspek | Bus | Ring | Star | Mesh | Tree |
|-------|-----|------|------|------|------|
| **Kabel** | Sedikit | Sedang | Banyak | Sangat Banyak | Banyak |
| **Keandalan** | Rendah | Rendah | Tinggi | Sangat Tinggi | Tinggi |
| **Biaya** | Rendah | Sedang | Sedang | Sangat Tinggi | Tinggi |
| **Troubleshooting** | Sulit | Sulit | Mudah | Sulit | Sedang |
| **Single Point Failure** | Kabel utama | Perangkat | Switch/hub | Tidak ada | Root |
| **Skalabilitas** | Buruk | Sedang | Baik | Buruk | Baik |
| **Penggunaan** | Jaringan kecil | Jaringan sedang | Paling umum | Jaringan kritis | Jaringan besar |

---

<span id="bab2-8"></span>

### 2.8 CARA MEMILIH TOPOLOGI YANG TEPAT

**Faktor-faktor yang Perlu Dipertimbangkan:**

**1. Biaya**
- Topologi bus: paling murah
- Topologi star: sedang
- Topologi mesh: paling mahal

**2. Keandalan**
- Topologi bus dan ring: kurang andal
- Topologi star: andal
- Topologi mesh: paling andal

**3. Jumlah Perangkat**
- Jaringan kecil: bus atau star
- Jaringan sedang: star atau tree
- Jaringan besar: tree atau mesh

**4. Kebutuhan Pengembangan**
- Perlu perluasan: star atau tree
- Tidak perlu perluasan: bus

**5. Ketersediaan Teknisi**
- Teknisi terbatas: star (mudah troubleshooting)

# BAB 3
## PROTOKOL JARINGAN DAN MODEL OSI

---

<span id="bab3-1"></span>

### 3.1 APA ITU PROTOKOL JARINGAN?

**Protokol jaringan** adalah seperangkat aturan dan standar yang mengatur bagaimana perangkat dalam jaringan berkomunikasi satu sama lain. 

**Bayangkan seperti ini:**

Bayangkan dua orang berbicara dalam bahasa yang berbeda. Mereka tidak akan bisa berkomunikasi. Protokol seperti bahasa yang sama yang digunakan oleh perangkat untuk "berbicara" satu sama lain.

**Definisi Formal:**

Protokol adalah aturan formal yang mengatur format, urutan, dan tindakan untuk komunikasi antar perangkat dalam jaringan. 

**Fungsi Protokol:**

1. Menentukan format data
2. Mengatur urutan komunikasi
3. Mendeteksi dan memperbaiki kesalahan
4. Mengatur kecepatan komunikasi
5. Mengatur alamat pengirim dan penerima

**Contoh Protokol:**
- TCP/IP - Protokol dasar internet
- HTTP - Web
- FTP - Transfer file
- DNS - Domain name
- SMTP - Email

---

<span id="bab3-2"></span>

### 3.2 PROTOKOL TCP/IP

**TCP/IP** adalah protokol yang digunakan di internet. Nama TCP/IP berasal dari dua protokol utamanya: TCP (Transmission Control Protocol) dan IP (Internet Protocol). 

**TCP/IP Model memiliki 4 lapisan:**

**1. Application Layer (Lapisan Aplikasi)**
- Berinteraksi dengan pengguna
- Contoh: HTTP, FTP, DNS, SMTP

**2. Transport Layer (Lapisan Transport)**
- Mengatur pengiriman data
- Contoh: TCP, UDP

**3. Internet Layer (Lapisan Internet)**
- Mengatur pengalamatan dan routing
- Contoh: IP, ICMP

**4. Network Access Layer (Lapisan Akses Jaringan)**
- Menghubungkan ke media fisik
- Contoh: Ethernet, Wi-Fi

---

**Perbandingan TCP dan UDP:**

| Aspek | TCP | UDP |
|-------|-----|-----|
| Koneksi | Connection-oriented | Connectionless |
| Keandalan | Tinggi (ada aknoledgment) | Rendah (tidak ada) |
| Kecepatan | Lambat | Cepat |
| Penggunaan | Web, email | Streaming, DNS |

---

<span id="bab3-3"></span>

### 3.3 MODEL OSI (OPEN SYSTEMS INTERCONNECTION)

**Model OSI** adalah model referensi yang dikembangkan oleh ISO untuk standarisasi komunikasi jaringan. Model OSI memiliki 7 lapisan. 

**Ilustrasi 7 Lapisan OSI:**

```
┌─────────────────────────────────────┐
│ Layer 7: Application (Aplikasi)      │ ← Berinteraksi dengan pengguna
├─────────────────────────────────────┤
│ Layer 6: Presentation (Presentasi)   │ ← Format data (enkripsi, kompresi)
├─────────────────────────────────────┤
│ Layer 5: Session (Sesi)              │ ← Mengatur sesi komunikasi
├─────────────────────────────────────┤
│ Layer 4: Transport (Transport)       │ ← Mengatur pengiriman data (TCP/UDP)
├─────────────────────────────────────┤
│ Layer 3: Network (Jaringan)          │ ← Pengalamatan dan routing (IP)
├─────────────────────────────────────┤
│ Layer 2: Data Link (Data Link)       │ ← Transfer frame (MAC address)
├─────────────────────────────────────┤
│ Layer 1: Physical (Fisik)            │ ← Media fisik (kabel, sinyal)
└─────────────────────────────────────┘
```

---

<span id="bab3-4"></span>

### 3.4 TUJUH LAPISAN OSI LAYER

**Layer 7: Application (Aplikasi)**

**Fungsi:**
- Interface antara aplikasi dan jaringan
- Menyediakan layanan untuk aplikasi

**Contoh Protokol:**
- HTTP (web)
- FTP (file transfer)
- SMTP (email)
- DNS (domain name)

**Contoh Perangkat:**
- Web browser
- Email client

---

**Layer 6: Presentation (Presentasi)**

**Fungsi:**
- Format data
- Enkripsi dan dekripsi
- Kompresi data

**Contoh:**
- SSL/TLS (enkripsi)
- JPEG, GIF, MPEG (format data)

---

**Layer 5: Session (Sesi)**

**Fungsi:**
- Mengatur sesi komunikasi
- Membuka dan menutup sesi
- Sinkronisasi

**Contoh Protokol:**
- NetBIOS
- RPC

---

**Layer 4: Transport (Transport)**

**Fungsi:**
- Pengiriman data end-to-end
- Flow control
- Error correction

**Contoh Protokol:**
- TCP (reliable)
- UDP (unreliable)

**Port Penting:**
| Port | Protokol | Aplikasi |
|------|----------|----------|
| 80 | TCP | HTTP |
| 443 | TCP | HTTPS |
| 25 | TCP | SMTP |
| 53 | UDP | DNS |
| 20/21 | TCP | FTP |

---

**Layer 3: Network (Jaringan)**

**Fungsi:**
- Pengalamatan IP
- Routing
- Packet forwarding

**Contoh Protokol:**
- IP (IPv4, IPv6)
- ICMP (ping)
- ARP

**Perangkat:**
- Router

---

**Layer 2: Data Link (Data Link)**

**Fungsi:**
- Transfer frame
- MAC addressing
- Error detection

**Contoh Protokol:**
- Ethernet
- Wi-Fi (802.11)
- PPP

**Perangkat:**
- Switch
- Bridge

---

**Layer 1: Physical (Fisik)**

**Fungsi:**
- Media fisik
- Sinyal listrik/optik
- Kecepatan transfer

**Contoh:**
- Kabel UTP
- Fiber Optik
- Sinyal Wi-Fi

**Perangkat:**
- Hub- Repeater

---

**Mnemonik untuk Mengingat 7 Lapisan:**

**Dari Bawah ke Atas:**
"Please Do Not Throw Sausage Pizza Away"
- Please = Physical
- Do = Data Link
- Not = Network
- Throw = Transport
- Sausage = Session
- Pizza = Presentation
- Away = Application

---

<span id="bab3-5"></span>

### 3.5 PERBANDINGAN MODEL OSI DAN TCP/IP

| Aspek | OSI | TCP/IP |
|-------|-----|--------|
| **Jumlah Layer** | 7 layer | 4 layer |
| **Pengembang** | ISO | DARPA |
| **Pendekatan** | Teoritis | Praktis |
| **Penggunaan** | Referensi | Implementasi |
| **Layer** | Application, Presentation, Session, Transport, Network, Data Link, Physical | Application, Transport, Internet, Network Access |

---

**Perbandingan Layer:**

```
OSI Model                 TCP/IP Model
────────────────────     ────────────────
Application      │
Presentation     ├─────── Application
Session          │
────────────────────
Transport        ├─────── Transport
────────────────────
Network          ├─────── Internet
────────────────────
Data Link        ├─────── Network Access
Physical         │
────────────────────
```

---

### 3.6 RANGKUMAN BAB 3

2. **TCP/IP** adalah protokol utama internet dengan 4 layer.

3. **Model OSI** adalah model referensi dengan 7 layer.

4. **7 Layer OSI:**
   - Application (aplikasi)
   - Presentation (presentasi)

   - Transport (transport)
   - Network (jaringan)
   - Data Link (data link)

   - TCP: reliable, lambat (web, email)

### 4.1 MEDIA TRANSMISI KABEL

**Media transmisi kabel** adalah jalur komunikasi yang menggunakan kabel untuk mengirimkan data. 

**A. Kabel UTP (Unshielded Twisted Pair)**

**Karakteristik:**
- Kabel dengan 4 pasang kabel pilin
- Tidak ada pelindung (unshielded)
- Paling umum digunakan
- Harga murah

**Kategori:**
| Kategori | Kecepatan | Penggunaan |
|----------|-----------|------------|
| Cat 5e | 100 Mbps - 1 Gbps | Jaringan standar |
| Cat 6 | 1 Gbps - 10 Gbps | Jaringan cepat |
| Cat 6a | 10 Gbps | Jaringan cepat |

**Konektor:**
- RJ45

---

**B. Kabel STP (Shielded Twisted Pair)**

**Karakteristik:**
- Ada pelindung (shielded)
- Lebih tahan interferensi
- Lebih mahal dari UTP

**Penggunaan:**
- Lingkungan dengan interferensi tinggi
- Jaringan industri

---

**C. Kabel Coaxial**

**Karakteristik:**
- Konduktor pusat dengan pelindung
- Digunakan untuk TV kabel
- Jarang untuk jaringan komputer

**Penggunaan:**
- TV kabel
- Jaringan lama (10Base2)

---

**D. Kabel Fiber Optik**

**Karakteristik:**
- Menggunakan cahaya untuk transmisi
- Kecepatan sangat tinggi
- Tahan interferensi
- Jarak jauh

**Jenis:**
| Jenis | Ukuran | Penggunaan |
|-------|--------|------------|
| Single-mode | 9/125 μm | Jarak jauh |
| Multi-mode | 62.5/125 μm | Jarak dekat |

**Kelebihan:**
- Kecepatan sangat tinggi (hingga 100 Gbps)
- Jarak jauh (hingga 100 km)
- Tahan interferensi

**Kekurangan:**
- Mahal
- Instalasi sulit
- Perlu peralatan khusus

---

### 4.2 MEDIA TRANSMISI NIRKABEL

**Media nirkabel** menggunakan gelombang elektromagnetik untuk mengirim data.

**Karakteristik:**
- Menggunakan gelombang radio
- Jarak: 10-100 meter
- Kecepatan: hingga 10 Gbps (Wi-Fi 6)

**Standar Wi-Fi:**

---

**B. Bluetooth (IEEE 802.15.1)**

**Karakteristik:**
- Jarak: 10-100 meter
- Kecepatan: hingga 2 Mbps
- Untuk PAN

**Penggunaan:**
- Headset

- Transfer file

---

### 4.3 PERANGKAT JARINGAN AKTIF DAN PASIF

**A. Perangkat Aktif**

Perangkat yang membutuhkan daya listrik untuk beroperasi. 

| Perangkat | Fungsi | Layer OSI |
|-----------|--------|-----------|

| **Firewall** | Keamanan jaringan | Layer 3/4 |

---

**B. Perangkat Pasif**

Perangkat yang tidak membutuhkan daya listrik.

| Perangkat | Fungsi |
|-----------|--------|

**Fungsi Perangkat Utama:**

**1. Switch**

Switch adalah perangkat yang menghubungkan perangkat dalam satu jaringan lokal (LAN). Switch bekerja di Layer 2 (Data Link).

**Fungsi:**

- Mengurangi collision

Router adalah perangkat yang menghubungkan jaringan yang berbeda. Router bekerja di Layer 3 (Network).

**Contoh:**

---

**4. Modem**

Modem adalah perangkat yang menghubungkan jaringan ke ISP.

**Fungsi:**
- Menghubungkan ke internet
- Mengubah sinyal analog ke digital

**Jenis Modem:**
- DSL Modem

# BAB 5
## IP ADDRESS DAN SUBNETTING

---

<span id="bab5-1"></span>

### 5.1 KONSEP IP ADDRESS

**IP Address** adalah alamat unik yang digunakan untuk mengidentifikasi perangkat dalam jaringan. IP address memungkinkan perangkat saling mengenali dan berkomunikasi. 

**Bayangkan seperti ini:**

IP address seperti alamat rumah. Untuk mengirim surat, kamu perlu tahu alamat rumah penerima. Untuk mengirim data di internet, komputer perlu tahu IP address tujuan.

**Definisi:**

IP Address adalah deretan angka biner 32-bit (IPv4) yang digunakan untuk mengidentifikasi perangkat dalam jaringan.

**Format IPv4:**

IP address terdiri dari 4 oktet yang dipisahkan dengan titik:
```
192.168.1.10
│   │   │  │
│   │   │  └── Oktet ke-4 (host)
│   │   └───── Oktet ke-3 (subnet)
│   └───────── Oktet ke-2 (network)
└───────────── Oktet ke-1 (network)
```

**Komponen IP Address:**

1. **Network ID** - Bagian yang menunjukkan jaringan
2. **Host ID** - Bagian yang menunjukkan perangkat dalam jaringan

---

<span id="bab5-2"></span>

### 5.2 KELAS IP ADDRESS

**Kelas IP Address berdasarkan oktet pertama:**

| Kelas | Oktet Pertama | Network | Host | Contoh |
|-------|---------------|---------|------|--------|
| **A** | 1-126 | 8 bit | 24 bit | 10.0.0.0 |
| **B** | 128-191 | 16 bit | 16 bit | 172.16.0.0 |
| **C** | 192-223 | 24 bit | 8 bit | 192.168.1.0 |
| **D** | 224-239 | Multicast | - | 224.0.0.1 |
| **E** | 240-255 | Experimental | - | - |

---

**Jumlah Host per Kelas:**

| Kelas | Jumlah Host | Jumlah Network |
|-------|-------------|----------------|
| A | 16.777.214 | 126 |
| B | 65.534 | 16.384 |
| C | 254 | 2.097.152 |

---

**IP Private (RFC 1918):**

IP private tidak bisa diakses dari internet dan digunakan di jaringan internal. 

| Kelas | Range IP Private |
|-------|------------------|
| A | 10.0.0.0 - 10.255.255.255 |
| B | 172.16.0.0 - 172.31.255.255 |
| C | 192.168.0.0 - 192.168.255.255 |

**IP Khusus:**
- **127.0.0.1** - Localhost (komputer sendiri)
- **0.0.0.0** - Semua interface
- **255.255.255.255** - Broadcast

---

<span id="bab5-3"></span>

### 5.3 SUBNET MASK, NETWORK ID, DAN HOST ID

**A. Subnet Mask**

**Subnet Mask** adalah angka 32-bit yang digunakan untuk membedakan Network ID dan Host ID. 

**Format:**
```
IP Address  : 192.168.1.10
Subnet Mask : 255.255.255.0
```

**Cara Membaca:**
- 255 berarti bit network
- 0 berarti bit host

---

**B. Network ID**

**Network ID** adalah alamat yang menunjukkan jaringan.

**Cara Menentukan:**
IP AND Subnet Mask

**Contoh:**
```
IP Address  : 192.168.1.10  = 11000000.10101000.00000001.00001010
Subnet Mask : 255.255.255.0 = 11111111.11111111.11111111.00000000
------------------------------------------------------------
Network ID  : 192.168.1.0   = 11000000.10101000.00000001.00000000
```

---

**C. Host ID**

**Host ID** adalah alamat yang menunjukkan perangkat dalam jaringan.

**Cara Menentukan:**
IP - Network ID

**Contoh:**
```
IP Address  : 192.168.1.10
Network ID  : 192.168.1.0
Host ID     : 10
```

---

**D. Broadcast Address**

**Broadcast Address** adalah alamat yang digunakan untuk mengirim data ke semua perangkat dalam jaringan.

**Cara Menentukan:**
Network ID + (2^n - 1) dimana n = jumlah bit host

**Contoh:**
```
Network ID  : 192.168.1.0
Host bits   : 8
Broadcast   : 192.168.1.255
```

---

<span id="bab5-4"></span>

### 5.4 KONSEP DASAR SUBNETTING

**Subnetting** adalah teknik membagi satu jaringan besar menjadi beberapa jaringan kecil (subnet). 

**Bayangkan seperti ini:**

Bayangkan sebuah sekolah dengan 1000 siswa. Jika semua siswa dalam satu kelas, akan sulit dikelola. Subnetting seperti membagi sekolah menjadi beberapa kelas yang lebih kecil.

**Tujuan Subnetting:**

1. **Efisiensi** - Mengurangi broadcast domain
2. **Keamanan** - Memisahkan jaringan
3. **Manajemen** - Memudahkan pengelolaan
4. **Optimasi** - Penggunaan IP lebih efisien

**Istilah dalam Subnetting:**

| Istilah | Penjelasan |
|---------|------------|
| **Subnet** | Jaringan kecil hasil pembagian |
| **Subnet Mask** | Menentukan batas subnet |
| **CIDR** | Notasi /n (contoh: /24) |
| **Host** | Perangkat dalam subnet |
| **Broadcast** | Alamat untuk semua host |

---

<span id="bab5-5"></span>

### 5.5 CIDR (CLASSLESS INTER-DOMAIN ROUTING)

**CIDR** adalah notasi yang menunjukkan jumlah bit network dalam subnet mask. 

**Format CIDR:**
```
192.168.1.0/24
│          │
│          └── jumlah bit network
└── network
```

**Tabel CIDR:**

| CIDR | Subnet Mask | Jumlah Host |
|------|-------------|-------------|
| /8 | 255.0.0.0 | 16.777.214 |
| /16 | 255.255.0.0 | 65.534 |
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /27 | 255.255.255.224 | 30 |
| /28 | 255.255.255.240 | 14 |
| /29 | 255.255.255.248 | 6 |
| /30 | 255.255.255.252 | 2 |

---

<span id="bab5-6"></span>

### 5.6 VLSM (VARIABLE LENGTH SUBNET MASK)

**VLSM** adalah teknik subnetting di mana setiap subnet dapat memiliki ukuran yang berbeda sesuai kebutuhan. 

**Contoh:**

```
Network: 192.168.1.0/24

Kebutuhan:
- Subnet A: 50 host
- Subnet B: 30 host
- Subnet C: 10 host

Solusi VLSM:
- Subnet A: 192.168.1.0/26 (62 host)
- Subnet B: 192.168.1.64/27 (30 host)
- Subnet C: 192.168.1.96/28 (14 host)
```

---

<span id="bab5-7"></span>

### 5.7 PERHITUNGAN SUBNETTING

**Rumus Dasar:**

```
Jumlah Subnet = 2^(bit subnet)
Jumlah Host = 2^(bit host) - 2
Blok Subnet = 256 - nilai desimal segmen terakhir subnet mask
```

**Contoh 1: /24**

```
Network: 192.168.1.0/24
Subnet Mask: 255.255.255.0
Bit host: 8
Host: 2^8 - 2 = 254
Network: 192.168.1.0
Broadcast: 192.168.1.255
Host: 192.168.1.1 - 192.168.1.254
```

**Contoh 2: /26**

```
Network: 192.168.1.0/26
Subnet Mask: 255.255.255.192
Bit host: 6
Host: 2^6 - 2 = 62
Jumlah Subnet: 4

Subnet 1: 192.168.1.0/26  (host: 1-62)
Subnet 2: 192.168.1.64/26 (host: 65-126)
Subnet 3: 192.168.1.128/26 (host: 129-190)
Subnet 4: 192.168.1.192/26 (host: 193-254)
```

**Contoh 3: /28**

```
Network: 192.168.1.0/28
Subnet Mask: 255.255.255.240
Bit host: 4
Host: 2^4 - 2 = 14
Jumlah Subnet: 16

Subnet 1: 192.168.1.0/28 (host: 1-14)
Subnet 2: 192.168.1.16/28 (host: 17-30)
...
```

---

**Langkah Perhitungan Subnetting:**

1. **Tentukan network dan subnet mask**
2. **Hitung jumlah host yang dibutuhkan**
3. **Tentukan bit host: 2^n - 2 >= host yang dibutuhkan**
4. **Tentukan bit subnet: 32 - bit network - bit host**
5. **Hitung jumlah subnet: 2^(bit subnet)**
6. **Tentukan blok subnet: 256 - nilai desimal segmen terakhir subnet mask**
7. **Tentukan alamat network, broadcast, dan host**

---

# BAB 6
## PENGALAMATAN DAN ROUTING DASAR

<span id="bab6-1"></span>

### 6.1 DNS (DOMAIN NAME SYSTEM)

**DNS** adalah sistem yang menerjemahkan nama domain (seperti google.com) ke IP address (seperti 142.250.190.46). 

**Bayangkan seperti ini:**

DNS seperti buku telepon internet. Kamu mencari nama orang (domain) dan dapat nomor teleponnya (IP address).

**Cara Kerja DNS:**

```
[User] → "google.com" → [DNS Server] → "142.250.190.46"
```

**Komponen DNS:**

1. **Root Server** - Server level tertinggi
2. **TLD Server** - Server untuk .com, .org, .id
3. **Authoritative Server** - Server untuk domain tertentu
4. **Resolver** - Server yang menerjemahkan

**Jenis Record DNS:**

| Record | Fungsi |
|--------|--------|
| A | Domain ke IPv4 |
| AAAA | Domain ke IPv6 |
| CNAME | Alias domain |
| MX | Mail server |
| NS | Name server |

---

<span id="bab6-2"></span>

### 6.2 DHCP (DYNAMIC HOST CONFIGURATION PROTOCOL)

**DHCP** adalah protokol yang memberikan IP address secara otomatis ke perangkat. 

**Bayangkan seperti ini:**

DHCP seperti petugas yang memberikan nomor rumah secara otomatis kepada setiap penghuni baru.

**Cara Kerja DHCP:**

1. **Discover** - Klien mencari DHCP server
2. **Offer** - Server menawarkan IP
3. **Request** - Klien meminta IP
4. **Acknowledge** - Server memberikan IP

**Keuntungan DHCP:**

1. Otomatis (tidak perlu konfigurasi manual)
2. Efisien (IP digunakan secara optimal)
3. Mudah (tidak perlu ahli jaringan)

---

<span id="bab6-3"></span>

### 6.3 KONSEP DASAR ROUTING

**Routing** adalah proses menentukan jalur terbaik untuk mengirim data dari sumber ke tujuan. 

**Bayangkan seperti ini:**

Routing seperti GPS. GPS menentukan jalur terbaik dari tempatmu ke tujuan. Router melakukan hal yang sama untuk data di jaringan.

**Komponen Routing:**

1. **Router** - Perangkat yang melakukan routing
2. **Routing Table** - Daftar jalur yang diketahui
3. **Next Hop** - Router berikutnya

**Cara Kerja Routing:**

1. Paket data datang ke router
2. Router cek alamat tujuan
3. Router cari di routing table
4. Router tentukan jalur terbaik
5. Router kirim ke next hop

---

<span id="bab6-4"></span>

### 6.4 PERBEDAAN ROUTING STATIS DAN DINAMIS

**A. Routing Statis**

Routing yang dikonfigurasi secara manual. 

**Karakteristik:**
- Dikonfigurasi manual
- Tidak berubah otomatis
- Untuk jaringan kecil

**Keunggulan:**
- Aman
- Tidak ada overhead
- Kontrol penuh

**Kekurangan:**
- Tidak adaptif
- Konfigurasi manual
- Tidak skalabel

**Contoh:**
```
ip route 192.168.2.0 255.255.255.0 192.168.1.2
```

---

**B. Routing Dinamis**

Routing yang dilakukan otomatis dengan protokol routing. 

**Karakteristik:**
- Otomatis
- Berubah otomatis
- Untuk jaringan besar

**Keunggulan:**
- Adaptif
- Otomatis
- Skalabel

**Kekurangan:**
- Ada overhead
- Kurang aman
- Kompleks

**Contoh Protokol:**
- RIP (Routing Information Protocol)
- OSPF (Open Shortest Path First)
- EIGRP (Enhanced Interior Gateway Routing Protocol)

---

**Perbandingan:**

| Aspek | Statis | Dinamis |
|-------|--------|---------|
| Konfigurasi | Manual | Otomatis |
| Adaptasi | Tidak | Ya |
| Overhead | Tidak | Ada |
| Keamanan | Tinggi | Sedang |
| Skalabilitas | Kecil | Besar |

---
