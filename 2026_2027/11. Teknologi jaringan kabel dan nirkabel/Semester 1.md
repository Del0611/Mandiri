## 📘 MINGGU 1: Pengantar Media Transmisi Jaringan

> **TP terkait:** TP 1  
> **Alokasi:** 4 JP (2 pertemuan × 2 JP)  
> **Level:** C2 (Memahami)

### 🎯 Tujuan Pembelajaran
1. Menjelaskan pengertian media transmisi
2. Mengklasifikasikan jenis-jenis media transmisi
3. Menjelaskan fungsi media transmisi dalam jaringan

### 📖 Materi

#### 1.1 Pengertian Media Transmisi

**Media transmisi** adalah segala sesuatu yang berfungsi sebagai **perantara** atau **jalur** untuk mengirimkan data/informasi dari satu perangkat (pengirim) ke perangkat lain (penerima) dalam sebuah jaringan komputer.

> 💡 **Analogi:** Bayangkan media transmisi seperti jalan raya. Data adalah kendaraan yang melintas, dan media transmisi adalah jalannya. Semakin lebar dan bagus jalannya, semakin cepat dan banyak kendaraan yang bisa lewat.

#### 1.2 Fungsi Media Transmisi

| Fungsi | Penjelasan |
|--------|-----------|
| **Menyalurkan data** | Menjadi jalur perpindahan bit data |
| **Menjaga integritas data** | Meminimalkan gangguan sinyal |
| **Menentukan bandwidth** | Kapasitas maksimal transfer data |
| **Menentukan jarak jangkauan** | Seberapa jauh sinyal dapat dikirim |
| **Menentukan kecepatan** | Latency dan throughput jaringan |

#### 1.3 Klasifikasi Media Transmisi

```
                        MEDIA TRANSMISI
                              │
              ┌───────────────┴───────────────┐
              │                               │
        GUIDED (Kabel)                 UNGUIDED (Nirkabel)
              │                               │
    ┌─────────┼─────────┐         ┌───────────┼───────────┐
    │         │         │         │           │           │
Twisted   Coaxial   Fiber       Radio      Microwave   Infrared
 Pair                Optic      Waves
```

##### A. Guided Media (Media Terarah / Berkabel)
Media transmisi yang **mengarahkan sinyal** melalui jalur fisik tertentu.

**Contoh:**
- Twisted Pair (UTP, STP)
- Coaxial
- Fiber Optic

##### B. Unguided Media (Media Tidak Terarah / Nirkabel)
Media transmisi yang **menyebarkan sinyal** melalui udara tanpa jalur fisik.

**Contoh:**
- Gelombang radio (Wi-Fi, Bluetooth)
- Microwave (VSAT)
- Inframerah (remote TV)

#### 1.4 Faktor Pemilihan Media Transmisi

| Faktor | Pertimbangan |
|--------|--------------|
| **Bandwidth** | Kebutuhan kapasitas data |
| **Jarak** | Dekat (< 100m) atau jauh (> 1km) |
| **Interferensi** | Lingkungan banyak gangguan atau tidak |
| **Biaya** | Anggaran instalasi & perawatan |
| **Fleksibilitas** | Mudah dipindah atau tidak |
| **Keamanan** | Tingkat kerahasiaan data |
| **Skalabilitas** | Kemudahan pengembangan |

#### 1.5 Perbandingan Umum Media Transmisi

| Aspek | Twisted Pair | Coaxial | Fiber Optic | Wireless |
|-------|--------------|---------|-------------|----------|
| **Bandwidth** | 100 Mbps - 10 Gbps | 10 Mbps - 1 Gbps | 1 - 100 Gbps | 11 - 9600 Mbps |
| **Jarak** | 100 m | 185 - 500 m | 500 m - 40 km | 10 - 100 m |
| **Biaya** | Murah | Sedang | Mahal | Sedang |
| **Interferensi** | Tinggi | Sedang | Tidak ada | Tinggi |
| **Instalasi** | Mudah | Sedang | Sulit | Sangat mudah |
| **Keamanan** | Sedang | Sedang | Sangat tinggi | Rendah |

### 🧪 Aktivitas Pembelajaran

**Pertemuan 1:**
- Diskusi kelas: "Apa yang terjadi jika media transmisi rusak?"
- Menonton video animasi transmisi data

**Pertemuan 2:**
- Kunjungan ke lab jaringan sekolah
- Mengamati jenis kabel yang digunakan
- Presentasi hasil pengamatan kelompok

### 📝 Latihan Soal

1. **Jelaskan** apa yang dimaksud dengan media transmisi!

## 📘 MINGGU 2: Twisted Pair & Fiber Optic (TP 1)

> **TP terkait:** TP 1  
> **Alokasi:** 4 JP  
> **Level:** C2-C3

### 🎯 Tujuan Pembelajaran
1. Menjelaskan struktur dan karakteristik kabel twisted pair
2. Menjelaskan struktur dan karakteristik fiber optic
3. Membandingkan kelebihan & kekurangan keduanya
4. Memilih media transmisi sesuai kebutuhan

### 📖 Materi

#### 2.1 Kabel Twisted Pair

##### A. Pengertian
**Twisted Pair** adalah kabel yang terdiri dari **pasangan kabel** yang dililitkan (twisted) satu sama lain. Pelilitan bertujuan untuk **mengurangi interferensi elektromagnetik** dan **crosstalk**.

##### B. Struktur Kabel UTP

```
┌─────────────────────────────────────┐
│         JACKET (Pelindung Luar)     │
│  ┌───────────────────────────────┐  │
│  │  ┌─────┐  ┌─────┐  ┌─────┐   │  │
│  │  │Pair1│  │Pair2│  │Pair3│   │  │
│  │  └─────┘  └─────┘  └─────┘   │  │
│  │  ┌─────┐                      │  │
│  │  │Pair4│                      │  │
│  │  └─────┘                      │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

**Komponen:**
1. **Konduktor tembaga** – 8 kabel (4 pasang)
2. **Insulator** – pelindung tiap kabel
3. **Jacket** – pelindung luar (PVC)

##### C. Jenis Twisted Pair

| Jenis | Keterangan | Gambar |
|-------|-----------|--------|
| **UTP** | Unshielded Twisted Pair – tanpa pelindung | Paling umum dipakai |
| **STP** | Shielded Twisted Pair – ada foil pelindung | Anti interferensi |
| **FTP** | Foiled Twisted Pair – foil per kabel | Kombinasi |

##### D. Kategori Kabel UTP

| Kategori | Kecepatan | Frekuensi | Penggunaan |
|----------|-----------|-----------|------------|
| Cat 3 | 10 Mbps | 16 MHz | Telepon |
| Cat 5 | 100 Mbps | 100 MHz | Fast Ethernet |
| **Cat 5e** | 1 Gbps | 100 MHz | Gigabit Ethernet |
| **Cat 6** | 1-10 Gbps | 250 MHz | Gigabit (100m) |
| Cat 6a | 10 Gbps | 500 MHz | 10G (100m) |
| Cat 7 | 10 Gbps | 600 MHz | Data center |
| Cat 8 | 40 Gbps | 2000 MHz | Data center |

##### E. Kelebihan & Kekurangan UTP

| ✅ Kelebihan | ❌ Kekurangan |
|-------------|--------------|
| Harga murah | Rentan interferensi |
| Mudah dipasang | Jarak max 100 m |
| Fleksibel | Kecepatan terbatas |
| Konektor mudah | Keamanan rendah |
| Banyak tersedia | Mudah disadap |

#### 2.2 Kabel Fiber Optic

##### A. Pengertian
**Fiber Optic** adalah kabel yang terbuat dari **serat kaca** atau **plastik** yang mentransmisikan data dalam bentuk **pulsa cahaya**.

##### B. Struktur Fiber Optic

```
┌────────────────────────────────────────────┐
│  JACKET (Pelindung Luar)                   │
│  ┌──────────────────────────────────────┐  │
│  │  STRENGTH MEMBER (Penguat)           │  │
│  │  ┌────────────────────────────────┐  │  │
│  │  │  CLADDING (Pemantul Cahaya)    │  │  │
│  │  │  ┌──────────────────────────┐  │  │  │
│  │  │  │  CORE (Inti - Kaca)      │  │  │  │
│  │  │  │                          │  │  │  │
│  │  │  └──────────────────────────┘  │  │  │
│  │  └────────────────────────────────┘  │  │
│  └──────────────────────────────────────┘  │
└────────────────────────────────────────────┘
```

**Komponen:**
| Komponen | Fungsi |
|----------|--------|
| **Core** | Inti, tempat cahaya merambat |
| **Cladding** | Memantulkan cahaya agar tetap di core |
| **Coating** | Pelindung core dari kerusakan |
| **Strength Member** | Penguat kabel (Kevlar) |
| **Jacket** | Pelindung terluar |

##### C. Prinsip Kerja

Cahaya masuk ke core dan **memantul total** (total internal reflection) di dalam core karena indeks bias cladding lebih rendah dari core. Cahaya merambat hingga ujung kabel.

```
Cahaya masuk →  ╲  ╱ ╲  ╱ ╲  ╱  → Cahaya keluar
                ╲╱   ╲╱   ╲╱
              [========== CORE ==========]
```

##### D. Jenis Fiber Optic

| Jenis | Core | Sumber Cahaya | Jarak | Bandwidth | Warna Jacket |
|-------|------|---------------|-------|-----------|--------------|
| **Single-mode (SM)** | 8-10 µm | Laser | 40 km+ | Sangat besar | Kuning |
| **Multi-mode (MM)** | 50-62.5 µm | LED | 500 m - 2 km | Besar | Oranye/Aqua |

**Perbandingan:**

```
SINGLE-MODE:
Core kecil ─── Cahaya lurus ─── Jarak jauh
[=========] →  →  →  →  →  →  → 40 km

MULTI-MODE:
Core besar ─── Cahaya memantul ─── Jarak pendek
[===========]  ╲╱╲╱╲╱╲╱╲╱  → 500 m
```

##### E. Konektor Fiber Optic

| Konektor | Keterangan |
|----------|-----------|
| **SC** | Square Connector – kotak, snap-in |
| **LC** | Lucent Connector – kecil, umum di data center |
| **ST** | Straight Tip – bulat, twist-lock |
| **FC** | Ferrule Connector – ulir, presisi tinggi |
| **MTRJ** | Mechanical Transfer RJ – 2 fiber |

##### F. Kelebihan & Kekurangan Fiber Optic

| ✅ Kelebihan | ❌ Kekurangan |
|-------------|--------------|
| Bandwidth sangat besar | Harga mahal |
| Jarak sangat jauh | Instalasi rumit |
| Anti interferensi EM | Alat khusus (fusion splicer) |
| Aman dari penyadapan | Rapuh |
| Ringan & tipis | Butuh ahli |
| Tidak berkarat | Sulit diperbaiki |

#### 2.3 Perbandingan Lengkap

| Aspek | Twisted Pair | Fiber Optic |
|-------|--------------|-------------|
| **Material** | Tembaga | Kaca/plastik |
| **Sinyal** | Listrik | Cahaya |
| **Bandwidth** | 100 Mbps - 10 Gbps | 1 - 100 Gbps |
| **Jarak** | 100 m | 500 m - 40 km |
| **Biaya kabel** | Murah | Mahal |
| **Biaya instalasi** | Murah | Mahal |
| **Interferensi** | Rentan | Tidak rentan |
| **Keamanan** | Rendah | Tinggi |
| **Perawatan** | Mudah | Sulit |
| **Umur pakai** | 5-10 tahun | 20-30 tahun |

#### 2.4 Studi Kasus: Memilih Media Transmisi

**Kasus 1: Warnet 20 komputer dalam 1 ruangan**
→ **UTP Cat 5e/6**  
Alasan: Jarak dekat, biaya murah, instalasi mudah.

**Kasus 2: Menghubungkan gedung A ke gedung B (2 km)**
→ **Fiber Optic Multi-mode**  
Alasan: Jarak > 100 m, butuh bandwidth besar.

**Kasus 3: Backbone ISP antar kota (50 km)**
→ **Fiber Optic Single-mode**  
Alasan: Jarak sangat jauh, butuh bandwidth sangat besar.

**Kasus 4: Kafe dengan pengunjung mobile**
→ **Wireless + UTP backbone**  
Alasan: Klien mobile, butuh fleksibilitas.

## 📘 MINGGU 3: Alat & Bahan Instalasi Jaringan (TP 2)

> **TP terkait:** TP 2  
> **Alokasi:** 4 JP  
> **Level:** C2

### 🎯 Tujuan Pembelajaran
1. Mengidentifikasi alat instalasi jaringan UTP
2. Mengidentifikasi alat instalasi jaringan fiber optic
3. Menjelaskan fungsi setiap alat

### 📖 Materi

#### 3.1 Peralatan Instalasi Kabel UTP

##### A. Crimping Tool (Tang Crimping)

```
      ┌──────────────────┐
      │   ┌────────┐     │
      │   │RJ45 Slot│    │
      │   └────────┘     │
      │    ╱╲  ╱╲        │
      │   ╱  ╲╱  ╲       │
      │  ╱ Tangkai ╲     │
      │ ╱          ╲     │
      └──────────────────┘
```

**Fungsi:**
- Memasang konektor RJ45 ke ujung kabel UTP
- Menjepit pin RJ45 agar terkunci
- Memotong kabel

**Jenis:**
- Crimping tool biasa (manual)
- Crimping tool ratchet (lebih presisi)

**Tips penggunaan:**
1. Pastikan kabel sudah tersusun rapi
2. Masukkan RJ45 hingga ujung kabel terlihat
3. Jepit dengan kuat hingga terdengar "klik"

##### B. LAN Tester

```
┌─────────────────────────────────────┐
│  MAIN UNIT          REMOTE UNIT     │
│  ┌────────┐         ┌────────┐      │
│  │ 1 2 3 4│         │ 1 2 3 4│      │
│  │ 5 6 7 8│         │ 5 6 7 8│      │
│  └────────┘         └────────┘      │
│   [RJ45]             [RJ45]         │
└─────────────────────────────────────┘
```

**Fungsi:**
- Menguji konektivitas kabel UTP
- Memastikan urutan pin 1-8 benar
- Mendeteksi kabel putus/short

**Cara membaca hasil:**
- **Normal (Straight):** Lampu 1-2-3-4-5-6-7-8 (kedua unit)
- **Crossover:** Lampu urutan berbeda (1-3, 2-6)
- **Rusak:** Lampu tidak menyala / tidak berurutan

##### C. Punch Down Tool

**Fungsi:**
- Memasang kabel ke patch panel / keystone jack
- Memotong sisa kabel secara otomatis

**Jenis:**
- Manual
- Impact (dengan pegas)

##### D. Cable Stripper

**Fungsi:**
- Mengupas kulit luar kabel UTP tanpa merusak konduktor

##### E. Konektor RJ45

```
      ┌──────────────────┐
      │  ┌────────────┐  │
      │  │ ▓▓▓▓▓▓▓▓  │  │ ← Pin 1-8
      │  │            │  │
      │  │  ╱      ╲  │  │
```

#### 3.2 Peralatan Instalasi Fiber Optic

##### A. Fusion Splicer

```
┌──────────────────────────────────┐
│   FUSION SPLICER                 │
│   ┌────────┐  ┌────────┐         │
│   │ Fiber  │  │ Fiber  │         │
│   │  Kiri  │  │ Kanan  │         │
│   └────────┘  └────────┘         │
│      ╲          ╱                │
│       ╲        ╱                 │
│        ╲      ╱                  │
│         ╲    ╱                   │
│          ╲  ╱                    │
│      [Layar LCD]                 │
└──────────────────────────────────┘
```

**Fungsi:** Menyambung dua serat optik dengan **laser** (arc discharge).

**Bagian:**
- V-groove (penahan fiber)
- Elektroda (pemancar busur)
- Layar LCD (monitor proses)
- Pemanas (untuk heat shrink)

**Tips:**
- Bersihkan fiber sebelum splicing
- Potong dengan cleaver presisi
- Kalibrasi alat sebelum digunakan

##### B. Optical Power Meter (OPM)

**Fungsi:** Mengukur **daya optik** (dBm) yang diterima.

**Kegunaan:**
- Uji loss kabel
- Uji kualitas sambungan
- Uji output transmitter

##### C. Visual Fault Locator (VFL)

**Fungsi:** Mengirim **laser merah** untuk mendeteksi:
- Titik putus kabel
- Bending berlebih
- Konektor kotor

**Cara pakai:**
1. Hubungkan VFL ke salah satu ujung fiber
2. Nyalakan laser
3. Amati titik merah di sepanjang kabel

##### D. Fiber Cleaver

**Fungsi:** Memotong ujung fiber optic dengan **sudut 90°** presisi.

**Jenis:**
- Manual
- Otomatis

##### E. Fiber Stripper

**Fungsi:** Mengupas jacket dan coating fiber tanpa merusak core.

##### F. Splicing Protection Sleeve

**Fungsi:** Melindungi titik sambungan fiber optic.

#### 5.1 Standar TIA/EIA-568

**TIA/EIA-568** adalah standar internasional yang mengatur:

**Tujuan:** Menjamin **kompatibilitas** antar perangkat dari berbagai merek.

#### 5.2 Standar 568A

**Urutan warna (pin 1-8):**

| Pin | Warna | Kode |
|-----|-------|------|
| 1 | Putih-Hijau | WH-GR |
| 2 | Hijau | GR |
| 3 | Putih-Oranye | WH-OR |
| 4 | Biru | BL |
| 5 | Putih-Biru | WH-BL |
| 6 | Oranye | OR |
| 7 | Putih-Coklat | WH-BR |
| 8 | Coklat | BR |

**Mnemonic:** **P**utih **H**ijau - **H**ijau - **P**utih **O**ranye - **B**iru - **P**utih **B**iru - **O**ranye - **P**utih **C**oklat - **C**oklat

#### 5.3 Standar 568B

**Urutan warna (pin 1-8):**

| Pin | Warna | Kode |
|-----|-------|------|
| 1 | Putih-Oranye | WH-OR |
| 2 | Oranye | OR |
| 3 | Putih-Hijau | WH-GR |
| 4 | Biru | BL |
| 5 | Putih-Biru | WH-BL |
| 6 | Hijau | GR |
| 7 | Putih-Coklat | WH-BR |
| 8 | Coklat | BR |

**Mnemonic:** **P**utih **O**ranye - **O**ranye - **P**utih **H**ijau - **B**iru - **P**utih **B**iru - **H**ijau - **P**utih **C**oklat - **C**oklat

#### 5.4 Perbedaan 568A vs 568B

| Pin | 568A | 568B |
|-----|------|------|
| 1 | Putih-Hijau | Putih-Oranye |
| 2 | Hijau | Oranye |
| 3 | Putih-Oranye | Putih-Hijau |
| 4 | Biru | Biru |
| 5 | Putih-Biru | Putih-Biru |
| 6 | Oranye | Hijau |
| 7 | Putih-Coklat | Putih-Coklat |
| 8 | Coklat | Coklat |

**Perbedaan hanya di pin 1, 2, 3, 6** (pasangan oranye & hijau bertukar).

> 📌 **Standar yang umum dipakai di Indonesia: 568B**

#### 5.5 Jenis Kabel Berdasarkan Susunan

##### A. Kabel Straight-Through

**Definisi:** Kabel dengan **urutan warna sama** di kedua ujungnya.

**Konfigurasi:**
```
Ujung A: 568B ─────────────────── Ujung B: 568B
      atau
Ujung A: 568A ─────────────────── Ujung B: 568A
```

**Penggunaan:**
- Komputer → Switch
- Komputer → Hub
- Router → Switch
- Switch → Switch (beda jenis)

**Diagram:**
```
[PC]───Straight───[SWITCH]───Straight───[ROUTER]
```

##### B. Kabel Crossover

**Definisi:** Kabel dengan **urutan warna berbeda** di kedua ujungnya.

**Konfigurasi:**
```
Ujung A: 568A ─────────────────── Ujung B: 568B
```

**Penggunaan:**
- Komputer → Komputer
- Switch → Switch (sama jenis)
- Router → Router
- Hub → Hub
- PC → Router (port LAN)

**Diagram:**
```
[PC]───Crossover───[PC]

[SWITCH]───Crossover───[SWITCH]
```

#### 5.6 Tabel Penggunaan Kabel

| Perangkat A | Perangkat B | Jenis Kabel |
|-------------|-------------|-------------|
| PC | Switch | Straight |
| PC | Hub | Straight |
| PC | Router (LAN) | Crossover |
| PC | PC | Crossover |
| Switch | Switch | Crossover |
| Router | Router | Crossover |
| Router | Switch | Straight |
| Switch | Hub | Crossover |
| Hub | Hub | Crossover |

> 💡 **Tips:** Perangkat **berbeda jenis** → Straight. Perangkat **sama jenis** → Crossover.

#### 5.7 Auto MDI-X

Perangkat modern (switch gigabit) biasanya sudah mendukung **Auto MDI-X**, yaitu kemampuan mendeteksi otomatis jenis kabel. Dengan Auto MDI-X, kabel straight **bisa** digunakan untuk semua koneksi.

Namun, untuk ujian praktik, **tetap wajib** bisa membuat keduanya!

#### 5.8 Panjang Maksimal Kabel UTP

| Standar | Panjang Max |
|---------|-------------|
| TIA/EIA-568 | 100 m |
| Horizontal run | 90 m |
| Patch cord | 5 m + 5 m |
| Total | 100 m |

**Mengapa max 100 m?**
- Sinyal melemah (attenuation)
- Delay meningkat
- Crosstalk meningkat

## 📘 MINGGU 6: Praktik Crimping Kabel Straight & Crossover (TP 3)

> **TP terkait:** TP 3  
> **Alokasi:** 4 JP

### 🎯 Tujuan Pembelajaran

2. Melakukan crimping kabel crossover
3. Memahami langkah-langkah crimping yang benar

### 📖 Materi

#### 6.1 Alat & Bahan

| Alat | Jumlah |
|------|--------|
| Crimping Tool | 1 |
| Cable Stripper | 1 |
| LAN Tester | 1 |
| Tang Potong | 1 |

| Bahan | Jumlah |
|-------|--------|
| Kabel UTP Cat 5e | 1 meter |
| Konektor RJ45 | 4 buah |
| Kabel Ties | 2 buah |

#### 6.2 Langkah-Langkah Crimping Kabel Straight-Through

##### Step 1: Kupas Kulit Kabel
```
Kabel UTP:
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
        ↓ (kupas ±2 cm)
   ▓▓▓▓
   ░░░░ ← 8 kabel terlihat
   ░░░░
   ░░░░
   ░░░░
```
- Ukur **± 2 cm** dari ujung
- Kupas dengan **cable stripper**
- **Jangan** sampai mengenai konduktor

##### Step 2: Buang Pelindung Silang
- Buang **filler** (pelindung silang) di tengah
- Buang **strength member** jika ada

##### Step 3: Susun Kabel
Susun sesuai **568B** (standar umum):
```
Putih-Oranye
Oranye
Putih-Hijau
Biru
Putih-Biru
Hijau
Putih-Coklat
Coklat
```

##### Step 4: Ratakan Ujung
- Pegang kabel dengan rapi
- Potong ujung agar rata ± 1 cm
- Pastikan tidak ada kabel yang tidak sejajar

##### Step 5: Masukkan ke RJ45
```
      ┌──────────────────┐
      │  ┌────────────┐  │
      │  │1 2 3 4 5 6 │  │ ← Pin
      │  │7 8         │  │
      │  │            │  │
      │  │ ▓▓▓▓▓▓▓▓▓  │  │ ← Kabel masuk
      │  └────────────┘  │
      │   ╱          ╲   │
      └──╱────────────╲──┘
```
- Masukkan kabel ke RJ45 **dari dalam** (pin 1 di kiri saat melihat dari atas dengan klip di bawah)
- Pastikan **setiap kabel masuk ke jalurnya**
- Ujung kabel harus **terlihat di depan RJ45**

##### Step 6: Crimping
- Masukkan RJ45 ke **slot crimping tool**
- Jepit dengan **kuat** hingga terdengar **"klik"**
- Lepas dari crimping tool

##### Step 7: Uji dengan LAN Tester
- Pasang ujung kabel ke **main unit** & **remote unit**
- Nyalakan LAN tester
- Amati urutan lampu:
  - **Normal:** 1-2-3-4-5-6-7-8 (kedua unit)
  - **Rusak:** Tidak berurutan / mati

##### Step 8: Ulangi untuk Ujung Lain
- Buat ujung B dengan **urutan yang sama (568B)**
- Lakukan crimping & uji

#### 6.3 Langkah Crimping Kabel Crossover

Sama dengan straight-through, tapi **ujung B berbeda**:

| Ujung A (568A) | Ujung B (568B) |
|----------------|----------------|
| Putih-Hijau | Putih-Oranye |
| Hijau | Oranye |
| Putih-Oranye | Putih-Hijau |
| Biru | Biru |
| Putih-Biru | Putih-Biru |
| Oranye | Hijau |
| Putih-Coklat | Putih-Coklat |
| Coklat | Coklat |

**Atau sebaliknya** (568B di A, 568A di B).

#### 6.4 Kesalahan Umum & Solusi

| Kesalahan | Akibat | Solusi |
|-----------|--------|--------|
| Urutan salah | Kabel tidak normal | Perbaiki urutan |
| Kabel tidak rata | Pin tidak kontak | Potong ulang |
| Kabel tidak masuk jalur | Short circuit | Susun ulang |
| Crimping kurang kuat | Pin tidak menembus | Crimping ulang |
| Kulit terkupas terlalu dalam | Konduktor rusak | Potong ulang |
| Ujung kabel tidak terlihat | Tidak terkunci | Masukkan lebih dalam |

#### 6.5 Tips Crimping yang Baik

1. **Gunakan kabel berkualitas** (Cat 5e/6)
2. **Ukur panjang dengan tepat**
3. **Susun kabel dengan rapi** sebelum masuk RJ45
4. **Pastikan ujung kabel terlihat** di depan RJ45
5. **Crimping dengan kuat** tapi jangan berlebihan
6. **Uji dengan LAN tester** sebelum digunakan
7. **Beri label** pada kabel

| Attenuation | < 24 dB @ 100 MHz |

#### 9.2 Prinsip Kerja Fiber Optic

**Hukum Snellius:** Cahaya akan memantul total jika sudut datang > sudut kritis.

**Total Internal Reflection:**
```
    Sinar datang
         ╲
          ╲  θ1
    ───────╲─────────────── Cladding (n2)
            ╲
    ═══════════════════════ Core (n1)
            ╱
    ───────╱───────────────
          ╱  θ2
         ╱
    Sinar pantul
```

**Syarat:**
- n1 (core) > n2 (cladding)
- Sudut datang > sudut kritis

#### 11.2 Pengujian dengan OPM (Optical Power Meter)

##### A. Persiapan
- **OPM** & **Light Source** (OLS)
- **Patch cord** referensi
- **Adapter** sesuai konektor

##### B. Prosedur Pengujian

**Step 1: Kalibrasi**
```
[OLS] ──── Patch cord ──── [OPM]
```
- Hubungkan OLS ke OPM dengan patch cord
- Catat **daya referensi** (P0)
- Simpan sebagai referensi

**Step 2: Ukur Daya**
```
[OLS] ──── Fiber diuji ──── [OPM]
```
- Hubungkan OLS ke salah satu ujung
- Hubungkan OPM ke ujung lain
- Catat **daya terima** (P1)

**Step 3: Hitung Loss**
```
Loss = P0 - P1 (dB)
```

##### C. Standar Loss

| Panjang | Loss Max (dB) |
|---------|---------------|
| < 1 km | 1.5 |
| 1-5 km | 3.0 |
| 5-10 km | 5.0 |
| > 10 km | 0.5/km |

**Loss per komponen:**
- Konektor: 0.3-0.5 dB
- Splicing: 0.1-0.3 dB
- Kabel: 0.2-0.35 dB/km

##### D. Contoh Perhitungan

**Kasus:** Fiber 2 km, 2 konektor, 1 splicing
```
Loss kabel    = 2 km × 0.3 dB/km = 0.6 dB
Loss konektor = 2 × 0.4 dB      = 0.8 dB
Loss splicing = 1 × 0.2 dB      = 0.2 dB
─────────────────────────────────────────
Total loss    = 1.6 dB
```
Jika hasil pengukuran ≤ 1.6 dB → **LULUS**

#### 11.3 Pengujian dengan VFL (Visual Fault Locator)

##### A. Fungsi
- Mendeteksi **titik putus** kabel
- Mendeteksi **bending** berlebih
- Cek **konektor** rusak

##### B. Prosedur
1. Hubungkan VFL ke salah satu ujung fiber
2. Nyalakan VFL (laser merah)
3. Amati **titik merah** di sepanjang kabel
4. Titik merah = lokasi masalah

```
[VFL] ══════════╳══════════
                 ↑
            Titik putus
            (cahaya keluar)
```

##### C. Tips VFL
- Gunakan **kacamata safety** (laser!)
- Jangan **lihat langsung** ke ujung fiber
- Untuk kabel panjang, gunakan **daya tinggi**
- VFL efektif sampai ± 5 km

#### 11.4 OTDR (Optical Time Domain Reflectometer)

**Fungsi:** Menganalisis fiber secara **menyeluruh**.

| Kemampuan | Keterangan |
|-----------|-----------|
| Ukur panjang | Presisi tinggi |
| Deteksi event | Splicing, konektor, bending |
| Loss per event | Dalam dB |
| Profil kabel | Grafik sepanjang fiber |

**Trace OTDR:**
```
Loss (dB)
   │
   │╲
   │ ╲___
   │     ╲___
   │         ╲___
   │             ╲___
```

### 📖 Materi

#### 15.1 Pengertian VoIP

**VoIP (Voice over Internet Protocol)** adalah teknologi yang memungkinkan **komunikasi suara** melalui jaringan **IP** (internet/intranet) bukan melalui jaringan telepon tradisional (PSTN).

**Analogi:**
```
Telepon Tradisional:
[HP] ─── PSTN ─── [HP]
     (sirkuit khusus)

VoIP:
[HP] ─── Internet ─── [HP]
     (paket data)
```

#### 15.2 Sejarah VoIP

| Tahun | Perkembangan |
|-------|--------------|
| 1973 | ARPANET voice transmission |
| 1995 | VocalTec Internet Phone |
| 1996 | ITU H.323 standard |
| 1999 | SIP (RFC 2543) |
| 2000s | Skype, Vonage |
| 2010s | WhatsApp, Zoom |
| 2020s | WebRTC, 5G VoIP |

#### 15.3 Prinsip Kerja VoIP

##### A. Proses Pengiriman Suara

```
┌─────────────────────────────────────────────────┐
│  1. Suara → Mikrofon → Sinyal Analog           │
│  2. Analog → ADC → Sinyal Digital              │
│  3. Digital → Codec → Kompresi                 │
│  4. Kompresi → Paket IP → Jaringan             │
│  5. Paket IP → Dekompresi → Digital            │
│  6. Digital → DAC → Analog → Speaker           │
└─────────────────────────────────────────────────┘
```

##### B. Diagram Alur

```
[Penelepon]                                    [Penerima]
    │                                              │
    │ Suara                                        │
    ▼                                              │
[Mikrofon]                                         │
    │ Analog                                       │
    ▼                                              │
[ADC] ─── Digital ─── [Codec] ─── Paket IP ─── [Jaringan]
                                                   │
                                                   ▼
                                              [Codec]
                                                   │
                                                   ▼
                                              [DAC] ─── Analog
                                                   │
                                                   ▼
                                              [Speaker]
```

#### 15.4 Komponen VoIP

| Komponen | Fungsi |
|----------|--------|
| **IP Phone** | Telepon berbasis IP |
| **Softphone** | Aplikasi telepon di PC/HP |
| **IP PBX** | Server pusat VoIP |
| **VoIP Gateway** | Penghubung VoIP ↔ PSTN |
| **SIP Server** | Mengatur sinyal SIP |
| **Media Server** | Menyimpan pesan suara |
| **Codec** | Kompresi/dekompresi suara |

#### 15.5 Protokol VoIP

##### A. SIP (Session Initiation Protocol)

**Fungsi:** Mengatur sesi komunikasi (menelepon, menerima, menutup).

**Metode SIP:**
| Metode | Fungsi |
|--------|--------|
| **INVITE** | Memulai panggilan |
| **ACK** | Konfirmasi |
| **BYE** | Menutup panggilan |
| **CANCEL** | Membatalkan |
| **REGISTER** | Registrasi user |
| **OPTIONS** | Cek kemampuan |

**Contoh SIP Flow:**
```
User A          Server          User B
  │               │               │
  │──INVITE──────→│               │
  │               │──INVITE──────→│
  │               │←──100 Trying──│
  │←─100 Trying───│               │
  │               │←──180 Ringing─│
  │←─180 Ringing──│               │
  │               │←──200 OK──────│
  │←─200 OK───────│               │
  │──ACK─────────→│──ACK─────────→│
  │←═════════ RTP ═══════════════→│
  │──BYE─────────→│──BYE─────────→│
  │               │←──200 OK──────│
```

##### B. RTP (Real-time Transport Protocol)

**Fungsi:** Mengirim **suara** dalam bentuk paket.

- Port: **UDP 16384-32767**
- Tidak ada jaminan pengiriman
- Real-time priority

##### C. RTCP (RTP Control Protocol)

**Fungsi:** Monitoring kualitas RTP.

##### D. Codec

| Codec | Bitrate | Kualitas | Bandwidth |
|-------|---------|----------|-----------|
| **G.711** | 64 kbps | Tinggi | 87.2 kbps |
| **G.722** | 64 kbps | HD | 87.2 kbps |
| **G.729** | 8 kbps | Sedang | 31.2 kbps |
| **G.726** | 32 kbps | Sedang | 55.2 kbps |
| **Opus** | 6-510 kbps | Adaptif | Variabel |
| **iLBC** | 15 kbps | Sedang | 39.2 kbps |

#### 15.6 Perangkat VoIP

##### A. IP Phone

```
┌─────────────────────────┐
│  ┌───────────────────┐  │
│  │   1  2  3         │  │
```

#### 17.7 Studi Kasus

##### Kasus 1: PC Tidak Dapat IP

**Gejala:** PC tidak dapat IP dari DHCP

**Analisis:**
1. Cek kabel → OK
2. Cek LED switch → OK
3. Cek ipconfig → 169.254.x.x (APIPA)

**Hipotesis:** DHCP server mati

**Perbaikan:**
1. Cek DHCP server
2. Restart DHCP service
3. Test ulang

**Hasil:** PC dapat IP 192.168.1.100

##### Kasus 2: Wi-Fi Lambat

**Gejala:** Wi-Fi lambat padahal dekat AP

**Analisis:**
1. Cek RSSI → -40 dBm (Excellent)
2. Cek kanal → banyak AP di kanal 6
3. Cek jumlah user → 20 user

**Hipotesis:** Kanal padat & overload

**Perbaikan:**
1. Ganti kanal ke 11
2. Aktifkan band steering ke 5 GHz
3. Batasi user dengan QoS

**Hasil:** Kecepatan naik dari 5 Mbps ke 45 Mbps

##### Kasus 3: VoIP Tidak Bisa Call

**Gejala:** Softphone register OK tapi tidak bisa call

**Analisis:**
1. Cek register → OK
2. Cek dial plan → ada
3. Cek CLI → error "No route to destination"

**Hipotesis:** Context salah

**Perbaikan:**
1. Cek `sip.conf` → context=internal
2. Cek `extensions.conf` → ada context internal
3. Reload dial plan

**Hasil:** Panggilan berhasil

4. **Satu perubahan** pada satu waktu
